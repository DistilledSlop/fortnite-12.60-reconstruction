# Bulk mutation storage recovery

`python3 porting/behavior/bulk_mutation_storage_runtime/prepare.py` scans the original image for complete parameterless native constant mutation bodies and writes proposals and a detailed report to `/tmp/gameplay-bulk-mutation-storage/`. The image SHA-256 is verified. The scan uses the same authoritative Bool `size_of_outer` agreement and conservative reflected/native occupancy model as `bulk_native_scalar_runtime/prepare.py`. Class selection, package, flags, generated parent and declaration, complete function body, class-local bounds, occupancy, and proposed interval agreement are required. A raw unsigned storage field preserves the exact bytes of a whole-width write; bitwise mutations preserve all unspecified bits. Initialization and unrelated writes are not inferred.

The current scan produces no proposals. The three AARDronePawn functions lack class and parent size evidence; USpatialFactionScreen lacks class size evidence. BuildingActor, FortPlayerControllerZone and FortWorldItem mutations overlap occupied storage. APlayerCameraManager is outside the selected classes and package/header scope. Other matching functions target reflected fields or lack this scanner's storage evidence and remain for their existing recovery path. The report records each matched body and blockers, including overlaps. No runtime behavior is claimed.
