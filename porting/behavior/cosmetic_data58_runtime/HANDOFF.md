# Playlist helper predicates

Eight reflected static execs are recovered from the late runtime image. Each wrapper reads Playlist and dispatches to the listed native body. The native body null-checks Playlist, initializes the shared native gameplay tag singleton, then searches both the explicit tags at +0xd0 and parent tags at +0xe0. `FGameplayTagContainer::HasTag` represents those searches and invalid-tag behavior. Creative mode additionally tests bit 0 of +0x9fc (`bEnableCreativeMode`) only after a successful tag match. Mobile uses the registered native tag at +0x2538.

Evidence windows pin the wrappers and complete native code through all return paths; some windows include alignment bytes or the next function prefix. Shared singleton and tag registration are implemented by `native_gameplay_tags_runtime`. No build or tests were run per assignment.
