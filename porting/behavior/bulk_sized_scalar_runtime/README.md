# Size-backed native scalar storage proposals

Run from the repository root with `python3 -I porting/behavior/bulk_sized_scalar_runtime/scan.py`. Capstone must be available in `/tmp/common-input-capstone`. The scanner reads the mapped original image at `/mnt/vibrato/fortnite-evidence/original-late-capture-1/image-125.runtime.bin` and checks its SHA-256 against `338c83a2314ccac1040a2c0bb520b893013cc7b58eda58e550da67f5d84de680`. It writes guarded bodies in this directory and manifest proposals and evidence to `/tmp/gameplay-bulk-sized-scalar/`; `--output-dir` changes the latter location.

The scanner invokes the reviewed `native_class_size_evidence_runtime/scan.py` extractor directly on the pinned image. Both class and parent must have unique reflection identities, unique registration targets, matching package and class strings, and a fully matched registration body. Any positive reflected Bool outer sizes must agree with the extracted size; conflicts abort. At least one of the two boundaries must lack a reflected Bool size. The generated declaration must identify the same original parent.

Complete inline or wrapper-to-complete-pure-leaf plain byte and dword reads must match the reflected Bool, Byte, Int or Float return, flags and ABI. Typed Byte returns are excluded. The storage interval must fit wholly between the original parent and class sizes. Reflected storage and canonical native fields are reserved; unresolved property grouping and occupancy are rejected, and unknown widths reserve through the next known offset or class end. Conflicting proposed intervals are rejected. Masks, constants, pointers, guessed sizes and impure calls are not accepted. The report records each registration target, boundary, matched wrapper and leaf where applicable.

These are source-level storage proposals. The generated declaration does not enforce original binary layout, and writers, construction and lifecycle remain unported. No initial value is invented. Integration and validation are required before promotion; these proposals alone do not establish runtime parity.
