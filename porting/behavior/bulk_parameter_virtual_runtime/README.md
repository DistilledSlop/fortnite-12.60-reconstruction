# Single-parameter ordinary virtual stubs

Run `python3 -I porting/behavior/bulk_parameter_virtual_runtime/prepare.py` from the repository. It writes proposed manifest entries and evidence to `/tmp/gameplay-bulk-parameter-virtual/{manifest-entries,report}.json`; it does not modify the canonical manifest. The scanner requires Capstone at `/tmp/common-input-capstone`, objdump, and the original mapped image pinned by SHA-256 in the script.

Only ordinary reflected native void functions with exactly one by-value float or project-class object pointer are considered. Reflection supplies the function, parameter name and type; exact parameter flags and array dimension exclude returns, references and other modifiers. Events, RPCs and static functions are excluded. The scanner skips already ported functions and existing generated out-of-line or inline definitions. The complete generated exec wrapper must match the corresponding `bulk_parameter_event_runtime` or `bulk_object_event_runtime` instruction sequence, including both decoding paths, fixed helpers, branches, frame advancement, argument placement and virtual call slot.

The class mapping must be unique, and the imported constructor proof must establish a unique vptr store to incoming `this`; the slot must lie in its contiguous code-pointer table and target the exact shared `c2 00 00` return stub. This proves the native leaf ignores the argument and has no effects. Ambiguity fails closed. Proposals retain the original function name, signature, reflection flags and `virtual: true`. They are source evidence only; promotion, compilation and runtime verification remain pending.
