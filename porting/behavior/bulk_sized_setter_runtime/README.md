# Sized scalar parameter setters

`scan.py` scans the pinned 12.60 runtime image for complete one-parameter bool, int32, and float FFrame thunks ending in a pure single store. It checks parameter and function metadata, local stack slots, both FFrame branch targets, generated parent declarations, and exact class-local bounds. Own and parent class sizes are extracted independently from uniquely indexed GPSC functions using the reviewed `native_class_size_evidence_runtime` extractor; reflected bool size evidence must agree. At least one size must lack reflected bool evidence, keeping this family separate from the ordinary setter scanner.

Reflected property spans, ported manifest fields, and annotated generated native fields must all be accounted for. Proposed overlapping intervals of incompatible type or extent are rejected. Existing manifest function and field names are checked for collisions. The scanner reads the current canonical manifest, including pending entries, and writes proposals only; it does not edit canonical sources or the manifest. The generated fields identify storage only; initialization and other writers remain unrecovered.

Run `python3 porting/behavior/bulk_sized_setter_runtime/scan.py` from the source root. It requires the pinned image and Capstone at the paths in the script. Generated bodies are local `.inc` files; `/tmp/gameplay-bulk-sized-setter/manifest-entries.json` and `report.json` contain proposals and scan evidence. The pinned-image scan produced nine functions and nine fields against the manifest present at scan time. Re-run after manifest changes before integration.
