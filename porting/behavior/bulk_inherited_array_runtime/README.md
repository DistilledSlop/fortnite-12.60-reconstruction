# Inherited reflected array count queries

`prepare.py` scans the pinned original image for complete zero-argument `int32` Num and `bool` empty/nonempty thunks, using the exact inline and wrapper/leaf instruction shapes of `bulk_array_query_runtime`. It considers only a unique inherited reflected `TArray` at count offset minus eight, with a unique selected FortniteGame/FortniteUI ancestry that agrees with generated C++ bases. It resolves the element's exact generated C++ type and requires a unique accessible declaration, compatible signature, and no canonical, maintained, or generated definition. The proposed expression qualifies the declaring owner. It adds no storage and writes proposals only.

Run `python3 -I porting/behavior/bulk_inherited_array_runtime/prepare.py`; output is `/tmp/gameplay-bulk-inherited-array/{manifest-entries,report}.json`. The 2026-11-03 scan found **zero candidates** among 23,758 inventory records; 21 recognized complete query shapes had no supported inherited field (18 lacked a supported ancestor, three lacked a unique matching field). The pinned image digest and rejection counts are in the report. No bodies were promoted, and no build or runtime verification was run.
