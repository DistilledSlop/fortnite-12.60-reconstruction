# Iterator actor-to-volume fallback: recovery in progress

`0x141c7c5c0` is not a player identity lookup and cannot be replaced by `NativeFindVolumeAtLocation`. It returns null immediately for a null actor or an empty manager `VolumeObjects` array. It computes the actor box once, traverses volumes in array order, skips null and the actor itself, and selects the first eligible volume unless a later eligible volume has both smaller X and smaller Y bounds extents (the floating-point ordering, including unordered cases, is visible in the assembly). Selection uses `NativeGetLocationBounds` semantics, including its missing-component behavior.

The actor box comes from the `ABuildingSMActor` static mesh component at +0x768, using its bounds if non-null; if null, the actor bounds virtual +0x548 is called with false. Other actors call that virtual with `only colliding components` false for `APawn` or `AInfo`, true otherwise, and the final argument false. `AController` and `APlayerState` are `AInfo`; pawns do not take the `AInfo` path. These are class tests, not exact class comparisons. The virtual result is an `FBox` converted to `FBoxSphereBounds` only when geometric containment is needed.

Each candidate first probes a native set at volume +0x318 with the actor weak-object key. `0x140782160` compares the two weak pointer words (object index and serial), so replacing this with a live object array or current geometric overlap loses behavior. For `AInfo`, only set membership qualifies a candidate. For other actors, membership qualifies directly; otherwise `0x141c6a510` tests the actor bounds. That helper repeats set membership, then for negligible bounds uses actor location with `NativeContainsLocation`; otherwise box volumes require both min and max corners inside volume bounds expanded by 175 units, and sphere volumes require the actor sphere to fit inside the volume sphere with the original 0.0001 tolerance. The helper's invalid-shape and edge branches need to be preserved exactly. Its box bounds helper `0x141c756c0` and floating-point ordering remain to be reviewed.

If there is no selected candidate and the actor is `AInfo`, an `IFortVolumeAccessor` native interface lookup is made. A process-global byte `0x14812316c` prevents recursive interface calls; while clear, it is set before virtual interface slot +0x10 and cleared afterwards. The returned pointer is passed through without validation. The guard is shared across all managers and actors, and is not thread-local. Non-`AInfo` actors have no interface fallback. The empty-volume early return also suppresses the interface fallback.

Blockers: volume +0x318 is an unreflected weak-key set whose construction and mutation must be integrated, and `IFortVolumeAccessor` has no recovered native method or implementations. The geometric box helper and precise unordered float branch need review. A source body assuming an empty set, a local guard, location-only selection, or a stubbed accessor would change observable behavior. No source or manifest entry is claimed ported here.
