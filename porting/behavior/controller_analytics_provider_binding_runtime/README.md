# Controller analytics provider interface

Proposed assigned names restore the native binding and getter, with real shared ownership and reference lifetime. `UFortAnalyticsControllerInterface` is the actual reflected interface. `NativeGetAnalyticsProvider` returns a reference to the provider slot owned by the controller's `UFortLocalPlayer` when `Player` has that type; otherwise it returns the controller's own fallback slot. The returned object must not be copied merely to obtain a raw pointer: Core analytics checks and later reloads the same slot. The native getter has no mutation or refcount increment. C++ const qualification is not recoverable from this code; the proposed mutable reference permits the observed reads.

Original image-125 evidence (window hashes in `native-evidence.json`):

* AFortPlayerController FClassParams 0x14649da30 points to 0x14649d9f0, where getter 0x1427ac4b0 and offset 0x5a0 are an interface pair. The getter jumps to 0x1427acdd0, the indexed GPSC for UFortAnalyticsControllerInterface (class block 0x1462bb280).
* Controller GPSC 0x142a3d9f0 -> internal constructor 0x142a3b0b0 -> constructor 0x142364800. Store 0x14236487d installs table 0x14612a1e8 at +0x5a0. Slot +0x28 points to 0x14237cff0. This target reads controller +0x290 (`Player`), tests its class against UFortLocalPlayer GPSC 0x142989f60, returns local player +0x258 when cast succeeds or controller +0x1a68 otherwise. 0x14178a8c0 and 0x14178bbfd demonstrate callers take the slot address and dereference it.
* Controller constructor zeroes +0x1a68/+0x1a70 at 0x142365982/0x142365989. Destructor 0x1419b9e25 decrements non-atomic strong and weak counts in +0x1a70's controller, calls virtual destruction at strong zero, and deletes the controller at weak zero. This is `TSharedPtr<..., ESPMode::NotThreadSafe>` ownership, not a bare pointer. UFortLocalPlayer GPSC -> thunk 0x142988640 -> constructor 0x142366a90 zeros its corresponding pair +0x258/+0x260. The observed event operation dispatches through the pointee vtable at +0xc8; this is not the corresponding slot in the local engine IAnalyticsProvider interface. The concrete native type and its other methods remain open. `FFortNativeAnalyticsProvider` is an assigned partial source contract, not a claim that the original pointee has that name or implements the local engine interface.

`source_policy.py` proposes a native interface base and class-owned fields; the generator needs explicit hooks for `interface_declarations` and `class_declarations` and its module must depend on Analytics. The added declarations are functional source members, not an asserted reproduction of byte offsets. Existing native provider initialization/assignment elsewhere must be ported separately; this getter does not create a provider. The manifest and include are proposals, not integrated or built. Other interface methods and other implementers remain outside this bounded recovery.

The partial contract declares the observed event dispatch as `NativeRecordEvent(const FString&, const TArray<FAnalyticsEventAttribute>&)`. Call sites pass addresses of the event string and attribute array and ignore the result; `void` and const qualifications are source-level choices consistent with that use, not independently proven original spelling. Native +0xc8 need not equal a recompiled source vtable offset. A future concrete provider must implement this same type and populate the owned slots; no adapter to the local engine provider is assumed. Controller slot copy/move helper 0x1423bd1f0 transfers both shared ownership words between controllers, and 0x142379354 reads the fallback pointer and invokes its +0x20 method, but neither establishes a concrete pointee type.
