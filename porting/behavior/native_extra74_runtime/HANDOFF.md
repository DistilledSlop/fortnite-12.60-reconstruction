# Native extra 74 behavioral lift

Targets: `0x142a53030` (PrepareRespawnForwardTarget) and `0x14195e100` (RemoveAllLootFromWorldForwardTarget). `rough.cpp` covers both generated function bodies, including the timer lookup early exit, ordered-positive delay check (NaN skips), allocation failure path, dynamic cleanup branches, post-callback local reload, reference-count release, and stack-cookie check. Source inventory and target list are alongside it. No tests, compilation, generation, promotion, or native binary changes were performed.

This is an intentionally non-linkable behavioral sketch. `Address`, raw frame access, all native calls, virtual dispatch, atomics, stack cookie and memory helpers require faithful ABI/effect adapters. Virtual adapters must read the current object's vtable at invocation, except `virtual_210`, which uses the table captured before the function lookup. Atomic add must return the old 32-bit value and implement native locked semantics. Frame slots must preserve byte-level aliasing, alignment and unspecified bytes; do not zero-initialize them. The byte copy from the callback descriptor includes four bytes not written locally. Stack frame and hidden arguments for `native_1446278d0`, including possible effects on live locals, require ABI validation; the decompiler does not expose the whole native call contract. `native_stack_cookie_frame_address` represents the actual native RSP at cookie creation/check, not the address of this C++ sketch's frame.

The target labels suggest intent but do not establish recovered engine types or ownership. Field offsets, vtable addresses and function addresses remain build-specific. Scalar bits in the first target follow the actual XMM3 store, despite the decompiler's undefined4 parameter. The loop-free cleanup branches reflect the assembly, including the count-nonzero/null-pointer path that bypasses delegate destruction and free. This is full control-flow coverage of the two inputs, but semantic/ABI coverage remains partial until the adapters and types are established.
