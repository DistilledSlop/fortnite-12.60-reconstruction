Four complete entries are proposed. `SetPickedUp` (0x142a2b990) and `SetCombinePickupsWhenTossCompletes` (0x142a2b7d0) store the normalized bool directly at +0x498 and +0x49c; bool_bits identifies these as the corresponding full-byte members. `SetOverrideInteractRadius` wrapper 0x142a2b910 calls 0x142038a20, which writes +0x4a4 only for authority; reflection maps that offset to OverrideInteractAimRadius. `RemovePickupInstigator` wrapper 0x1427630e0 consumes its two parameters and calls Stub_Empty; parameter order comes from offsets, not reflection's reversed parameter listing.

Remaining candidates are unclosed. The OnRep wrappers and several other wrappers dispatch through virtual slots, whose actual native bodies are not established by the wrappers. `GetItemEntry` 0x14202ecb0 selects the primary entry if the multi-entry array is empty and index is zero, otherwise selects a valid array index, else copies a static default; the generated FFortItemEntry has no matching native constructor and 0x142023c10 initializes nonzero values, so using FFortItemEntry() would be wrong. Container loot, search tier, indicator and pickup target paths have unresolved native functions or state. Registry operations involve weak object references, authority checks, delegate operations and helper calls; they need deeper closure before promotion. RaiseTreasure invokes an unresolved reflected event before setting a bit. This directory deliberately contains no speculative stubs for these.
