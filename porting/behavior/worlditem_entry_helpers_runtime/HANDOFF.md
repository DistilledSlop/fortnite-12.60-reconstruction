# World item entry helpers

These generator-ready fragments adapt the two closed helpers from `worlditem_population_runtime/EntryHelpers.h`. Their `UFortWorldItem` static names and explicit entry arguments are assigned integration contracts, not claims about original source declarations. The GUID string is by value, as in the native call. `FGuid::Parse` writes directly to the existing GUID and its return value is forwarded. The parent setter assigns the weak pointer before `bIsReplicatedCopy`.

`native-evidence.json` pins complete contiguous bodies of both source functions and the parse dispatcher at 0x142ca0820 in the original runtime image. The existing population handoff documents the parser equivalence and unresolved surrounding lifecycle. The enclosing population routine and dirty propagation remain unclosed and are not included here. Fragments have not been integrated, built, or tested.
