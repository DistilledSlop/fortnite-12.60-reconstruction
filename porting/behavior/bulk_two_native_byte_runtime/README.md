Original FBoolPropertyParams SetBitFuncs establish the parameter offsets omitted by the extracted parameter records.

No native byte fields or bodies qualify. `AFortGameStateZone::SetBuildingAllowed` writes bytes 0xe14 and 0xe15, which `bool_bits.json` identifies as reflected Boolean fields `bAllowBuildingAtLayoutRequirements` and `bAllowBuildingWithoutLayoutRequirements`. `UFortServerBotManagerAthena::DirtyBotFactions` ORs bytes 0x4b0 and 0x4b1, also reflected Booleans (`bIsCachedPlayerBotFactionsDirty` and `bIsCachedNoneParticipantsBotFactionsDirty`), and the GPSC proof is missing for both class and parent. Whole-byte writes/ORs must not be replaced with bitfield assignments without separately proving preservation of all bits; no such claim is made here. No build or runtime tests were run.
