# Uncounted control-flow lifts

These are working notes, not callable source or complete bodies. Original addresses refer to files in `native96-impl` and `native97-deps`.

* `SetPendingSkydiveLaunch` 0x14234e8b0 writes bit 0x10 at pawn +0x10e7 from normalized input and returns immediately when false. On true it obtains the ability system, creates gameplay-cue/effect data referring to the pawn, iterates effect handles and executes associated operations, then releases the temporary containers and shared references. It clears bit 0x04 at +0x10e7, conditionally casts PlayerState and calls both 0x1424293c0 and 0x1424293d0 with true, and if Controller exists and net mode != 1 queries its 0x610 virtual for a class and calls 0x1418bfe90(result, 3). Exact cue tags, ref-counted effects and virtual bindings are unresolved; preserve order and reentry.
* `TeleportToSkyDive` 0x141a267c0 retains the input height only when `height > 1000.0f` is ordered true; otherwise it substitutes `10000.0f`, including unordered NaN (`COMISS` / `JA`). It adds this height to the root-component position Z (or global default location if no root), obtains root rotation while updating its quaternion-to-rotator cache on component mismatch, calls pawn virtual 0x4f0 with location and rotation plus two zero flags, then calls 0x140c31764(pawn, 1). The identity of this last effect and precise virtual remain unresolved. Do not use a comparison rewrite that changes NaN behavior.
* `SetMeshHeightAdjustAthena` 0x141a24c60 requires actor role byte 3. It stores input at reflected MeshHeightAdjustAthena even if mesh is null. With a mesh, it updates cached relative rotation if invalid, calls 0x144122860 with relative translation (0, 0, input), cached relative quaternion and zero flags, then calls pawn virtual 0x760 with current transform components. Calls and rotation-cache details still need identification.
* `SetPetType` 0x14234e8d0 is not a pointer assignment: if net mode != 1 and input exists, it queries a world subsystem, checks it for this pawn and invokes a subsystem mutation; the subsequent code includes diagnostics, multiple object references and lifecycle operations. Retain full decompile until all bindings and side effects are mapped.
* `SetCharacterBodyVisibilityForPossession` 0x141a23e80 iterates exactly six `CharacterPartSkeletalMeshComponents`, invokes 0x144124180(component, bVisible, 2) on each non-null entry, and returns true if any existed. That call must be distinguished between the internal SceneComponent visibility and hidden-in-game setters before it can become a body.
* `SetBalloonRope` and `SetPossessedProp` first broadcast distinct global native multicast delegates with (pawn, new, old), then write the reflected property. Their helper 0x140aae720 walks the invocation list backwards, locks it during callbacks, and compacts stale entries afterward. `SetPossessedProp` additionally requires authority and turns a pending-kill/destroying argument to null first. There is no reflected equivalent for the two global delegate bindings yet.
