# Direct embedded-struct Boolean getters

`prepare.py` scans the reflected native inventory for parameterless Boolean getters whose complete original thunk and leaf read a direct reflected Boolean member of a directly embedded reflected struct. It accepts a full byte set by `mov byte ..., 1`, or a single bit extracted with normalization and set by a matching `or byte` setter. Both the complete function code and struct property record and setter are read from the original image pinned by SHA-256 in the script. The generated C++ must have unique named outer and inner members, and the modules must be the same or have a proven generated public dependency, include, and export. It excludes existing canonical entries, maintained/generated definitions, ambiguous metadata, deeper or inherited fields, and unsupported assembly. Proposals and detailed evidence are written to `/tmp/gameplay-bulk-struct-bool/`; the `.inc` files are source proposals and require integration by the owner of the canonical manifest.

The pinned scan found three direct full-byte reads: `AFortPlayerPawn::GetVehicleOverrideExit`, `UFortPerkWidget_NUI::IsTierPerk`, and `UFortTrackMovementComponent::IsReverseDirection`. The report records exact wrapper and leaf assembly, property offsets, and original setter assembly. A failed match makes no claim about behavior outside this finite family.
