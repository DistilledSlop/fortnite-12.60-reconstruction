# Reflected embedded struct scalar getters

`prepare.py` scans selected FortniteGame/FortniteUI classes against the SHA-256 pinned original runtime image. It proposes parameterless Int/Float native execs whose entire original code is either an inline dword copy or the exact standard exec wrapper calling a complete `mov`/`movss` scalar leaf. It also recognizes the corresponding virtual exec wrapper, but accepts it only after the existing hardened constructor proof establishes a unique vtable store through original `this`, and the requested slot is inside its contiguous table. The entire target leaf must match. Unsupported forms are rejected.

For every candidate, the read offset must equal the sum of a reflected, non-array class Struct property offset and a reflected, non-array Int/Float member offset, with matching generated C++ declarations for both. Resolution must be unique. Return metadata must be the exact by-value primitive return descriptor, with matching raw kind, offset zero and no type references or container aliases. Both reflected properties must be top-level; the member raw kind and type references must match the primitive. Struct and class packages must match their generated modules, and the struct name must be unique. Cross-module structs additionally require the owning header to include the exact generated struct header, the owning module to list the struct module as a public dependency, and the struct declaration to carry that module’s API export macro. Canonical manifest class/function pairs, generated header declarations and maintained/generated C++ definitions are excluded. No storage or default values are invented. This scanner does not attempt bools, inherited struct members, ungenerated declarations, or other leaf shapes. Constructor proof and vtable extraction reuse `bulk_virtual_scalar_runtime/prepare.py` and `build_vtable_slots.py`.

Run `python3 porting/behavior/bulk_struct_scalar_runtime/prepare.py`. Evidence and proposals are written to `/tmp/gameplay-bulk-struct-scalar/report.json` and `manifest-entries.json`; accepted bodies live here. The report includes original wrapper and leaf assembly, offsets, and virtual proof where applicable. These are proposals, not canonical manifest entries. No build or tests were run in this recovery pass.
