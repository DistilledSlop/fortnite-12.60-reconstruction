# Parameterless native event stub recovery

Run `python3 -I porting/behavior/bulk_native_event_runtime/prepare.py` from the repository. It writes proposed entries and evidence to `/tmp/gameplay-bulk-native-event/{manifest-entries,report}.json`; it never modifies the canonical manifest. Requires the Capstone installation at `/tmp/common-input-capstone`, objdump, and the original mapped image. The image SHA-256 is pinned to `338c83a2314ccac1040a2c0bb520b893013cc7b58eda58e550da67f5d84de680`.

The scanner matches the complete original zero-argument exec wrapper instruction sequence, including frame advancement, virtual call slot and (for bool) return storage. It accepts only native Blueprint events with supported flags, exact empty arguments or single scalar bool return metadata, unique selected non-interface target class mapping and no existing port. It follows the class's unique GetPrivateStaticClass through InternalConstructor to the constructor, uses `build_vtable_slots.py` to identify constructor vptr stores, and accepts a single vptr store only when its base is proven to be an unmodified callee-saved copy of incoming `this`. Thunk vptr stores, ambiguous constructors and slots outside the contiguous code-pointer table are rejected. Table slots must point to the exact shared stub bytes `c20000` (void), `b001c3` (true), or `32c0c3` (false). The report records each full chain and slot.

Entries name the `_Implementation` function and retain the original dispatcher exec address and numeric reflection flags. The generator must support `native_event_impl` and emit the reflected dispatcher and implementation correctly. This is source-only evidence; no canonical promotion, build, or runtime test is performed here. Results vary as the canonical manifest changes.
