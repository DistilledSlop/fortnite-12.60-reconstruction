It requires exact primitive return metadata and complete original inline, direct-call, or proven virtual wrapper and scalar leaf shapes. The summed offset must resolve uniquely through a class struct property and either two nested struct properties or a struct-super property. Generated types must be unique and match their modules; cross-module links require the actual include, public dependency, and API export. Existing manifest entries, header declarations, and C++ definitions are excluded. It does not handle bools or invent storage or defaults.
