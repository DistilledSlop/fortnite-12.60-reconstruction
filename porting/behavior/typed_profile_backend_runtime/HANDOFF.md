# Typed base profile backend proposal

`McpProfileBackend.h/.cpp` provide a logical, typed owner for the independently recovered base ID index and group index. The base constructor establishes empty C++ containers and a virtual table; it does not claim to reconstruct the full original constructor, binary layout, other fields, or other virtual slots. The virtual `FindGroup` is the base lookup; `FindBaseGroup` supplies the equivalent base-subobject lookup. Both return borrowed arrays. `InsertItem` adds the item to the ID map, then indexes the alternate key and template ID in that order. `InsertGroup` performs lower-bound insertion by item ID, leaving the existing group member on a folded-equal ID. Item pointers must be valid. The two indexes retain their own non-thread-safe shared references. The spelling, constness and visibility of the C++ methods are source proposals, not recovered symbols or exact ABI.
