# Multi-parameter ignored leaf probe

`python3 porting/behavior/bulk_ignored_multi_runtime/probe.py` inventories two-record native reflection functions with ordinary non-RPC/event/editor/static flags in the SHA-256-pinned original image. It disassembles up to the first return and records direct calls whose target begins with `c3`, plus wrappers with exactly two calls each to the known FFrame Step and StepExplicitProperty entry points and no other calls. Evidence: `/tmp/gameplay-bulk-ignored-multi/probe.json` (regenerable, not committed). This is a coarse discovery probe, **not** a behavior scanner: it does not prove parameter direction or count after splitting metadata, instruction control flow, direct-native body identity, class selection, or declaration safety. It emits no proposals or body credit.

2026-11-03 result: 1,791 eligible two-record reflection entries, zero direct `c3` call sightings, two step-only sightings. Both sightings share exec `0x1451914f0` for `UAthenaCustomizationScreen::ShiftItemsVariantOption` and `UAthenaCustomizationScreenBase::ShiftItemsVariantOption`. The wrapper appears to extract object and int inputs and advance the frame without invoking a native body. However, promoting either requires proving the shared wrapper's relationship to the underlying native definitions and inheritance/declarations, and verifying the complete exact wrapper control flow and metadata. Two aliases of one wrapper do not justify generalizing the single-parameter direct-leaf scanner. The probe does not search `ret 0`, wrappers with more than two reflection records, or other optimization patterns. No build, runtime, or tests were run.
