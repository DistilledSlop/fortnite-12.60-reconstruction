# Native POD field-copy getter proposals

Run `python3 porting/behavior/bulk_native_copy_runtime/prepare.py` to scan the pinned, SHA-256-checked runtime image. The scanner writes guarded `.inc` proposals here and `/tmp/gameplay-bulk-native-copy/{manifest-entries,report}.json`; `--output-dir` changes the latter destination and `--revalidate-own` includes this family's already ported entries. The report records complete wrapper/leaf instructions, class bounds and GPSC evidence. No canonical files are changed.

This extends `bulk_struct_copy_runtime` and `bulk_name_sret_runtime` to class-local **unreflected** storage. It accepts only exact reflected zero-argument returns of FName (8 bytes) or the listed, exact CoreUObject POD structs whose package, name and size agree with TypeTables: FVector, FRotator, FVector2D, FLinearColor, FGuid, FColor, FQuat and FVector4. Return flags must be exactly Parm|OutParm|ReturnParm with the expected native/public property flag, with no references or arrays. No FText, containers, strings, owning wrappers, constructor or default evidence is inferred.

Both class and immediate parent sizes require unique reviewed direct GPSC `sizeof` extraction, checked against any reflected Bool class size; the complete copied interval must lie within the declaring class. The generated class parent must agree with reflection. Reflected and canonical member occupancy is conservative: known scalar widths are used, unknown representations occupy through the next known offset, and malformed, unaccounted or ambiguous occupancy rejects the class. Generated annotated native fields must agree with canonical manifest entries. Proposed fields must not overlap. This identifies storage only; initialization and writers remain unported.

The instruction proof accepts only the full P_FINISH frame advance followed by an unchanged, exactly complete byte copy, or a complete sret wrapper calling a straight-line leaf with the same copy and correct output pointer return. Wrapper stack temporaries must fit the allocated stack area, except the established 8-byte FName caller-stack temporary at `[rsp+0x38]` with `sub rsp,0x20`. No other instructions, arithmetic, branches, calls or incomplete copies qualify. Selected classes and exact signatures are checked; an absent generated declaration is expected before opt-in, while incompatible declarations, actual maintained definitions and already ported functions are rejected. Proposals are source recovery only and need integration and validation.

Integrated in native source batch 13 (2026-11-03): 20 bodies and 20 supporting fields. Source generation is fail-closed; compilation and runtime validation remain pending at the shared approximately 2,040-body checkpoint. This is source coverage, with no feature or milestone parity claim.
