# Enum immediate predicates

`prepare.py` scans the SHA-256-pinned original runtime for complete zero-argument Boolean native thunks containing a byte comparison and `setcc`, either inline or through an exact single-call wrapper. It resolves a unique reflected field through a verified generated-class ancestry and checks its accessibility and generated declaration. Enum references must resolve through `TypeTables` and the generator. A `Byte` enum has byte storage; an `Enum` must have an explicit byte underlying property and a generated `enum class : uint8` declaration. Signed condition codes cast to `int8`, while unsigned and equality comparisons use `uint8`. Dword enum comparisons, ambiguous fields, missing underlying records, inaccessible or hidden inherited members, and partial bodies are rejected.

Run `python3 porting/behavior/bulk_enum_predicate_runtime/prepare.py`; `--output-dir` changes the default `/tmp/gameplay-bulk-enum-predicate` report location. `--revalidate-own` includes canonical manifest entries owned by this directory. Existing differing include files cause an error. Manifest entries are proposals and do not modify the canonical manifest. These are source recoveries, not runtime validation.
