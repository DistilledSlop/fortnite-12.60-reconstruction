# Radius impulse mutations

Reflection `native_funcs.json` supplies exec addresses, flags, parameter types, order and return. Native captures `maps-wind-impulse-lifecycle/_adhoc/0x141dd6cc0__141dd6cc0.c` and `0x141dda420__141dda420.c` supply bodies; Remove exec is captured under `maps-wind-live-consumers`. The native gate is dedicated-server, Fort.Wind live value and byte 0x44f, shared with AddWindImpulse. Both functions search the radius array at 0x2a0 for the first handle UID at element +0x48. Miss warnings use the proven LogFortWind category, Warning verbosity.

Remove writes previous magnitude from current, desired magnitude zero, then both blend fields from its argument. Set writes previous magnitude from current, desired magnitude and both blend fields from the input. Only when any location component or radius compares unequal, Set copies location and desired radius, stores the unchanged current radius as previous, and recomputes valid world bounds centered at the new location with the current radius as extent. This order deliberately does not use the incoming desired radius as bounds extent. Set returns true upon a match and false on a gate or miss. Neither operation removes an array element. Native sampling initialization remains unported; validation is pending.
