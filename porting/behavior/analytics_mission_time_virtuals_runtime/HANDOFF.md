# Analytics mission text and Athena match time

This proposal supplies both actual base implementation bodies and the two previously outstanding AssetLoadAnalyticsNative bindings. Assigned names are not claims about original symbols. The public declarations must be integrated as virtual methods and calls must use virtual dispatch; `Bindings.cpp` calls those methods on the runtime object. The `.inc` bodies may be promoted independently, but complete behavior for derived classes requires preserving their own overrides in the correct slots. Adding new virtuals at arbitrary positions is not evidence of a correct native ABI. The generated declarations currently do not contain these native virtuals, so these files are not yet build-ready without integration. Method const qualification is proposed, not independently established by x64 ABI.

Constructor tracing using `build_vtable_slots.py` Image and the original runtime image establishes GPSC -> internal constructor thunk -> constructor -> this primary-vptr store. AFortMission: `1429da8e0 -> 1429daaf0 -> 1420abbd0 -> 146091330`; slot +690 -> `1420ba150`. The reflection index's `1459eb9f8` is an unverified shared candidate and is not the primary vptr. Mission target loads MissionInfo at +260, returns its FText at +6c8, or invokes `142c0c240` (FText default constructor) if null. Reflection identifies both fields, including MissionName +6c8. It copies the FText with shared-reference ownership; ordinary C++ FText return preserves this. The caller uses the hidden return slot as FText and converts it to string.

AFortGameStateAthena: `14290f690 -> 1429165f0 -> 14197f7b0 -> 145e0ab78`; slot +780 -> `141995500`. It returns 0 when byte +1cb0 is below 3; otherwise calls virtual +630 and subtracts float +12dc. Reflection identifies GamePhase and AircraftStartTime and the enum identifies Aircraft as 3. Slot +630 base target `144216b40` calculates world time plus game state delta (or zero when world is null), matching UE AGameStateBase::GetServerWorldTimeSeconds; retain its virtual call. Values above known phases still enter subtraction, as in the unsigned byte comparison.

Raw addresses are in raw-pins.json. Existing source/manifest search found no canonical body for either target. Include `UFortMissionInfo.h` with MissionText.inc and the appropriate Athena declarations/enum with AthenaMatchTime.inc when integrating; add this directory and asset-load directory to include paths for Bindings.cpp. No canonical files, generated output, builds, tests, or commits changed.
