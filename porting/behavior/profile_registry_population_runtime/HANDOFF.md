# Profile registry population

The writer is identified for the UFortMcpProfile initialization override, but a source method is not proposed until the base initializer's full behavior and original signature are recovered. The override at `0x1421e0f60` calls base `0x1411044d0` with its incoming arguments, then inserts `GiftBox` → `UFortGiftBoxItem` into the map at the same profile object's `+0x30`. This is an initialization virtual, not the constructor: `0x1460d3390 + 0x288` points to the override and the base vtable's same slot points to `0x1411044d0`. The constructor `0x1421c3450` invokes the base constructor, installs that derived vtable, initializes derived fields, and returns without registering the class. Do not infer that the registry remains empty after construction.

The override calls class getter `0x14292de30`, whose class registration name at `0x1463f76a2` is `FortGiftBoxItem`. It passes selector `0x6b` to `0x141f23770`. Its jump-table case `0x141f24be5` returns a lazily initialized FString; initialization at `0x141f284e1` copies the eight UTF-16 code units `GiftBox\0` from `0x145bfbc68`. It passes the map at `this+0x30`, an output temporary, the addresses of the FString and class pointer, and zero to `0x140a871f0`. The latter constructs an owned key and class-pointer element at 0x20-byte sparse stride and calls `0x14069b9a0` to hash/link it. When the key already exists, `0x14069b9a0` frees the existing key allocation, replaces the existing 0x18-byte key/value pair with the newly constructed one, and returns the newly allocated sparse slot to the free list. Thus repeated initialization replaces the value for that key. The class pointer is not locally destroyed.

A second, distinct derived vtable `0x1460d3670` has initializer slot `0x1421e0fb0`, which calls the same base initializer and performs multiple registrations into its object's `+0x30`; its class identity and full list are not established here. Do not attribute those mappings to UFortMcpProfile. `evidence.json` pins raw windows from the original image; no evidence gate, source integration, build, runtime, or behavioral test was run. Follow-up: recover the complete base initializer and signature and validate source-engine string hash/equality before proposing integration.
