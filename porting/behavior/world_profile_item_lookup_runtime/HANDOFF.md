# World profile in-flight item lookup

No source or manifest is proposed: actual request ownership, mutation and exact typed state are still incomplete. The first array element at `UFortMcpProfileWorld +0x150` is **an in-flight save request**, not `FProfileEntry` or a base profile backend. `0x1425360c0` logs `UFortMcpProfileWorld::SavePlayerUpdates`, rejects a nonempty request array as an update already in progress, appends a 0xe8-byte request, creates a GUID at request +0x34, and copies the request to other involved profile objects. It initializes and copies the two FString sets at request +0x48 and +0x98. `0x142548630` diagnostic calls this a request and matches that GUID; its shipped assembly loops forever on mismatch, so do not infer a normal traversal from decompiler output. `0x142530760` initializes the array in the World constructor. These facts establish ownership but do not establish complete request structure or the distinct meanings/writers of its two sets. No substitute fields or source body are claimed.

`0x14254c270` tests array count > 0, then checks membership of the by-value FString in the first request's set +0x48 followed on a miss by +0x98; either hit returns true. The input temporary is always destroyed. `0x140ace810` shows FString set slots stride 0x18 and uses `0x142bcf780` case-folded comparison, as described in `profile_backend_installation_runtime/HANDOFF.md`. `0x14253c450` logs a hit as an item just removed and marks a newly created item pending delete, but this does not establish that both sets exclusively contain removed IDs. `0x14254c150` repeats the lookup using a world item's virtual +0x470 ID; `0x142532580` sets item byte +0xd1 when a hit occurs. Source names are unproven.

Owning-controller helper `0x1421d8de0` invokes profile virtual +0x150 and reads that object's weak array at +0x1c8 (`0x14468fb70` returns its array pointer and index 0). It iterates, resolves each weak object, casts to `AFortPlayerController`, compares controller +0xac0 against profile +0xa8, and returns first match.
