# Size-backed native packed bit getter proposals

Run from the repository root with `python3 -I porting/behavior/bulk_sized_bit_runtime/scan.py`. Capstone must be available in `/tmp/common-input-capstone`. The scanner checks the SHA-256 of the original mapped image at `/mnt/vibrato/fortnite-evidence/original-late-capture-1/image-125.runtime.bin` against `338c83a2314ccac1040a2c0bb520b893013cc7b58eda58e550da67f5d84de680`. It writes guarded bodies here and manifest proposals and evidence to `/tmp/gameplay-bulk-sized-bit/`; `--output-dir` changes the latter location.

The scanner invokes the reviewed `native_class_size_evidence_runtime/scan.py` extractor directly on the pinned image. Both class and parent require unique reflection identities and registration targets, matching package and class strings, and a fully matched registration body. Positive reflected Bool outer sizes must agree with the extracted sizes; conflicts abort. At least one boundary must lack a reflected Bool size. The generated declaration must identify the same original parent.

Only complete inline or exact wrapper-to-complete-pure-leaf zero-argument Bool getters reading a single normalized bit are matched. Flags and ABI are checked. The byte must fit between original parent and class boundaries and be unoccupied by reflected or canonical native fields. Unresolved property grouping and occupancy are rejected; unknown widths reserve through the next known offset or class end. Conflicting proposed intervals are rejected. Compatible getters sharing a byte use one `uint8` field without a default. The report records both registration targets, boundaries, assembly, and wrapper leaf when present. `--revalidate-own` includes this pass's canonical entries for revalidation; existing body files must match exactly.

These are source-level storage proposals. Generated declarations do not enforce original binary layout, and writers, construction and lifecycle remain unported. Integration and validation are required before promotion; these proposals alone do not establish runtime parity.
