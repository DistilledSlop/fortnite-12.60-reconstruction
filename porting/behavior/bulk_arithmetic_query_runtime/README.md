# Float-to-integer query recovery

`prepare.py` scans the SHA-256-pinned original runtime image for exact complete zero-argument reflected `Int` getters: the standard frame wrapper calls a leaf consisting solely of `cvttss2si eax, dword ptr [rcx + offset]; ret`. The offset must resolve to exactly one same-class reflected `Float` scalar and the generated header must declare that field as `float`. Function flags, class/package, return shape, access and any existing declaration are checked; unsupported shapes are rejected. The generated expression truncates toward zero and returns INT32_MIN for NaN, infinity, and values outside the signed 32-bit range, matching the instruction's result with masked floating-point exceptions. Floating-point exception status is not modeled.

Run `python3 porting/behavior/bulk_arithmetic_query_runtime/prepare.py`; proposals and evidence default to `/tmp/gameplay-bulk-arithmetic-query/{manifest-entries,report}.json`. `--output-dir` changes that location and `--revalidate-own` includes canonical entries from this directory. Existing differing includes cause an error. These are isolated proposals, not canonical manifest changes. No build or runtime validation is implied.
