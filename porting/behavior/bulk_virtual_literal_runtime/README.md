# Ordinary virtual scalar literal returns

Run `python3 -I porting/behavior/bulk_virtual_literal_runtime/prepare.py`. This writes proposals and evidence to `/tmp/gameplay-bulk-virtual-literal/{manifest-entries,report}.json`; it does not edit the canonical manifest. It checks the pinned mapped image SHA-256 and uses the same complete wrapper, unique GPSC/constructor, hardened `proven_this_store`, no thunk stores, and complete contiguous virtual-slot proof as `bulk_virtual_scalar_runtime`. It excludes the six separately proposed UFortItem queries, canonical ports, maintained definitions, and existing generated declarations/definitions. Entries retain reflected access, constness, flags, and virtual dispatch.

Only parameterless ordinary native methods with exact return flags, raw kind, array dimension, offset and no type references are considered. Exact byte ABI uses `mov al,imm8; ret`; Int and UInt32 use `mov eax,imm32; ret`. Float requires a complete RIP-relative `movss xmm0,[rip+disp32]; ret` from a readable initialized-data PE section without write permission. The emitted nine-significant-digit decimal must round-trip to the identical IEEE-754 bits; nonfinite and negative-zero values are excluded. Object/null returns are not scanned because their reflected class type and dependency require separate resolution. No event or RPC is accepted. Reports include wrapper, slot chain, complete literal bytes and, for floats, constant location, section and bits.

Current manifest: 48 matched wrappers; three candidate base implementations, all exact `return -1` (`b8ffffffffc3`): AFortTeamInfo::GetTeamExperience, AFortTeamInfo::GetTeamLevel, and UFortItem::GetLevelRelativeCostForRarityUpgrade. These do not establish derived overrides. Twenty-four matched targets are not supported literal leaves and 21 have ambiguous constructor/vtable evidence. Counts vary with canonical manifest state; `--revalidate-own` excludes this directory's already promoted entries. This is source evidence only; no build or runtime validation was performed.
