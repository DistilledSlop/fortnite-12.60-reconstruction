# Ordinary parameterless virtual stub recovery

Run `python3 -I porting/behavior/bulk_virtual_scalar_runtime/prepare.py` from the repository. It writes `/tmp/gameplay-bulk-virtual-scalar/{manifest-entries,report}.json` without changing the canonical manifest. `--revalidate-own` includes entries already promoted from this directory. It requires the Capstone installation at `/tmp/common-input-capstone`, objdump, and the original mapped image pinned by SHA-256 in the scanner.

The scanner accepts ordinary reflected native functions only, excluding Blueprint events, RPCs, static functions, unsupported flags, reference returns and array returns. It matches the complete parameterless exec wrapper and the return storage ABI for void, bool, int32 or float. For the unique selected, non-interface class it follows GetPrivateStaticClass through InternalConstructor to a unique constructor vtable store, proving that the store targets the original `this`. It rejects thunk stores, ambiguous constructors and slots outside the contiguous code-pointer table. The slot must target an exact complete return stub: shared void and boolean stubs at the pinned addresses, or a recognized integer/float zeroing instruction followed immediately by return. The emitted function is virtual so dispatch through derived classes is preserved; access and const qualification come from reflection. Every proposal records the chain in the report. The output is source-only, and needs promotion review and the next scheduled integration build; no runtime parity is claimed.
