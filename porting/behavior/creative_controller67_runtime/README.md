# Creative controller broad pass

`rough.cpp` is non-buildable behavioral pseudocode with unresolved effects named by address; it is not a source-complete candidate. Sources are the generated improved controller execs and `_Implementation` / `_Validate` bodies. Header argument names in improved exec output are assigned backwards for these RPCs; the volume null check and structure layout were recovered from the actual stack order and struct offsets, not those names. By-value copies explain apparent UObject field accesses and destruction in the decompiler. The original generated headers describe `_Implementation` parameters as const references, so the ABI and ownership require correction before promoting any body.

* `UpdateCreativePlotData`: exec 0x142a5d930; implementation 0x141a00cb0; validator 0x141a00cf0. Validator requires a non-null volume, then checks string lengths title 3–40, introduction <=1024, locale <=10; the category-gated log does not affect the result. Strings with Num=0 are empty; others are measured excluding the terminator. Implementation only destroys its copy.
* `PublishCreativePlot`: exec 0x142a59b30; implementation 0x1419ec120; validator 0x1419ec130. Validator rejects null volume; otherwise transforms/copies tags with 0x1419d9d90 and 0x140a1aad0, then delegates validity to 0x1419ddfd0. Do not assume whether tags are filtered or valid without recovering these helpers. Implementation only destroys its copy.
* `SendPhysicsBallHitToServer`: exec 0x142a5a430, implementation 0x1406801c0, validator 0x1406801d0. Validator returns true, implementation does nothing. The reflected declaration has six arguments; native `_Validate` and `_Implementation` are absent from the generated header, and improved exec parameter labels are unreliable. MANIFEST entries are `skipped`, not implementations.
* `OnRep_CreativeIslands` exec/inlined body 0x142a59730: normalize each island's 20-byte value at +0x10, then acquire an online interface. If absent broadcast change; if present convert values to strings, reset them, and invoke interface vtable +0x10 with an allocated weak-controller delegate. The callback and helper semantics remain unresolved; asynchronous behavior is inferred, not established by the indirect call alone. Empty list broadcasts immediately.
* `OnServerMarkerAdded` exec/inlined body 0x142a597d0 deep-copies a marker argument then calls 0x1419e8930; body of that helper is unresolved. Member lifetime and copy semantics reflected in sketch.
* `OnMinigameEnded` exec/inlined body 0x142a596a0. Four independent game-state predicates cause calls through +0x1f68 with corresponding configured values, `false`, and reason labels. It always calls 0x1423e5ec0 after the checks. No MANIFEST record for this exact class/function.
* `OnMinigameStarted` is already drafted in [respawn broad pass](../respawn_broad66_runtime/rough.cpp); not duplicated here. No exact controller MANIFEST entry.

The exact `(AFortPlayerControllerAthena, function)` MANIFEST records for all six RPC implementation/validation functions are `skipped`; `OnRep_CreativeIslands`, `OnServerMarkerAdded`, and `OnMinigameEnded` have no exact record. No canonical edits, build, tests, or commits were performed.
