## Producer and lifecycle closure

The 0x143e8b0b0 body (0x146 bytes, SHA-256 `2e54668c692f2fad19518092fcb62e7e5d7c5dd77e66dccb558c501c7690e312`) has the same contract and effects as UE 4.25 `UGameplayTagsManager::AddNativeGameplayTag`: it returns an invalid tag for None or when manager byte +0x183 is nonzero, otherwise checks and inserts the name in the native-tag set at +0xd0, adds a tag table row using the native source, and returns the name pair. 0x141ec98b0 passes `(Native)` as its comment (UTF-16 at 0x1459eb8c8), matching the engine default argument. The singleton is initialized once by 0x141ed1800, not separately per predicate. This affects actual state: the engine binds `DoneAddingNativeTags` to `OnPostEngineInit`; a first `AddNativeGameplayTag` after finalization returns an invalid tag. Deferring these five to the first playlist query can therefore differ when another singleton caller ran before finalization and the playlist query runs after it. Eager unconditional startup registration also changes behavior in the converse order. Neither substitution preserves the recovered trigger.
