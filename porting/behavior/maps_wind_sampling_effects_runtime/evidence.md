# Sampling effects and update ordering

Evidence: `porting/generated/maps-wind-impulse-lifecycle/_adhoc/0x141ddfad0__141ddfad0.c` and engine headers under `/opt/fortnite/UnrealEngine/Engine/Source/Runtime`. This is an integration plan, not a compiled implementation or runtime validation.

* Wind gate: `NativeIsWindEnabled()`; dedicated test: `GetNetMode() == NM_DedicatedServer`. On dedicated, `UE_LOG(LogFortWind, Log, TEXT("AFortWindManager::TickActor() called on dedicated server.  No need to tick on the dedicated server.  In fact, this actor should not EXIST on dedicated server!  Destroying it."))`, then `Destroy(false, true)` and return. Raw verbosity 6 is Log.
* Obtain `UWorld* World = GetWorld()`; null logs `UE_LOG(LogFortWind, Error, TEXT("AFortWindManager::TickActor() has nullptr MyWorld.  Cannot update wind impulses."))` and returns. Otherwise use world time at +0x548; `GetTimeSeconds()` is the engine accessor candidate, subject to confirming target layout.
* The raw GUObjectArray item bit is PendingKill; use `GUObjectArray.ObjectToObjectItem(Actor)->IsPendingKill()`, not `IsValid` which adds unreachable checks. `Actor->GetActorLocation()` uses root location and returns zero for null root.
* The spatial methods are `NativeWindResponderTree_0x2e0->Remove(Index, Box2D)` and `->Insert(Index, Box2D, nullptr)` with `Box2D` constructed from XY min/max. No null-tree guard is present in raw. The old index is removed first; if swapping, remove last and insert removed index with last bounds before modifying arrays.
* Use `MID->SetScalarParameterByIndex(Index, Value)` and `MID->SetVectorParameterByIndex(Index, Value)`; ignore boolean return. Wire the matching integrated NativeGetWindImpulseCylinder, NativeSetupAnimatingMaterials, NativeAdvanceWindDelta, NativeBuildWindSectionBoxes, NativeStartQueuedWindDelta and cylinder event dispatchers. Verify by-value cylinder events create the constructor UID as captured.
* Scope named engine stats around responder update and radius update, respectively; the draft BeginStat/EndStat interface cannot directly model lexical `SCOPE_CYCLE_COUNTER` without a lifetime-bearing scope. Do not invent silent no-op hooks.

The smooth expression must preserve floating operation grouping: `T2 = T*T; Alpha = T2*3.0f - (T2+T2)*T`. Radius interpolation is not clamped; completion sets radius and magnitude but does not refresh bounds. Only interpolating a changed radius refreshes bounds. Reverse iteration and swap removal match the capture.

Delta interpolation uses the same grouped smooth expression. Capture selects lower and upper by testing `(Desired - Previous) < 0`, then computes `Target = Alpha * (Desired - Previous) + Previous`. Clamp is explicitly `Result = Lower; if (Lower <= Target) { Result = Target; if (Upper <= Target) Result = Upper; }`. This preserves the captured unordered comparison behavior, unlike a generic min/max/clamp sequence. If already at desired, advance immediately without building section boxes; otherwise build boxes once after update even on completion, then advance when complete. At completion remove the active delta, update matched cylinder magnitude and changing flag, dispatch completion before pending flag update, dispatch death before cylinder swap removal, start next queue item unless a same-cylinder delta is first. Release section boxes before reverse cleanup of zero, idle, nonpending cylinders.
