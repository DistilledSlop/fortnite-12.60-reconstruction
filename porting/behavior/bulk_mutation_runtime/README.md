# Complete parameterless mutation sweep

Run `python3 porting/behavior/bulk_mutation_runtime/prepare.py` from any directory. The script pins the original runtime image SHA-256, decodes whole exec bodies through `ret`, and accepts two exact FFrame.Code increment sequences followed by one immediate scalar store. It rejects networking, static/const/event and unsupported access flags, unselected or ambiguous classes, unmatched reflected field types, and incompatible generated field declarations. Float constants are emitted only for exactly representable integer-valued finite floats (excluding negative zero). FFrame advancement belongs to the exec wrapper and is not emitted as gameplay behavior. Proposals and full matched assembly/rejection reasons are written to `/tmp/gameplay-bulk-mutation/{manifest-entries,report}.json`; canonical sources are untouched.

2026-11-03: 23,758 reflection records scanned; five complete source-only bodies proposed, no build or runtime validation. Eight other complete patterns have no usable reflected scalar field, including two bitwise patterns. Their native storage/bit layouts must be established before promotion. Parameter-bearing setters require matching their complete FFrame extraction paths and all side effects, a separate broad recognition opportunity; they are intentionally excluded here. The sweep does not assert coverage of wrapper calls, parameter extraction, other instruction encodings, or non-Fortnite packages.
