# Vehicle velocity virtual dispatch (blocked)

`base-bodies.draft` records the original base formulas for `GetDesiredForwardVelocity` and `GetDesiredForwardVelocityDelta`; neither is ready for promotion. The first calls virtual slot `0x8c0` and multiplies its float result by the native constant; the second calls virtual `0x890` then `0x898` and subtracts, in that order. Captures: `porting/generated/native111-virtual-targets/0x1418ec250.c` and `0x141915ad0.c`; reflected wrappers `0x14283b510` and `0x14283b550` dispatch virtually at `0x890` and `0x8b0`. Their declarations and dependencies must remain virtual in the reconstructed hierarchy.

`vtable-observations.json` lists primary vtable slots read from the original image, using captured constructors collected in `target_filter163_runtime/native-evidence.json`. This is a bounded set, not exhaustive coverage of Blueprint-derived or dynamically generated classes; `AFortAthenaSMVehicle` is omitted because the narrow constructor-store scan does not establish its final primary vtable. Among observed tables, Antelope and Goat replace slot `0x890` with `0x1418c36a0` and `0x1418ec270`; Ferret and Doghouse replace `0x8c0` with `0x1418ec210`. All observed tables retain the base `0x8b0` and `0x898` targets. The override captures are in ignored `porting/generated/vehicle-velocity-overrides`. Antelope and Goat overrides depend on subclass-specific mode, secondary-interface virtual calls, unproven properties and native helpers; Ferret/Doghouse override depends on unproven subclass storage and helper. Base `0x8c0` (`0x141915a00`) also requires gear arrays, input state and virtual calls. Current velocity `0x1419157e0` projects the vector at actor +0xc40 onto a transformed axis when the actor +0x130 component exists, or onto a global fallback axis otherwise; storage mapping, transform and fallback remain unclosed. None has complete dependency closure.

Original wrappers for forward speed (`0x878`), total speed (`0x888`) and previous forward speed (`0x8b8`) have base targets but invoke the same unclosed secondary movement interface or transform; `GetVehicleVelocity` itself dispatches through secondary vtable +0x4f8, so replacing it with actor velocity or a fixed vector is unsupported. Promotion requires all relevant overrides and helper contracts, followed by generation and affected integration validation. No manifest entries, build or runtime tests were made. Read-only Ghidra probes were rolled back; Ghidra reported project metadata changes on open.
