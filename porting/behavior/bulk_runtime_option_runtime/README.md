Only complete zero-argument frame wrappers and exact direct leaves calling the provider and reading a byte or float are accepted. Functions must be selected, unported and have compatible flags and signatures; the field must resolve uniquely in that reflected class at the actual offset and have a matching generated declaration. Bool fields additionally require the reflected full-byte `mov8`/mask 1 representation and a generated `bool`. The generator resolves the runtime options header from the typed CDO expression; FortniteUI uses its established FortniteGame dependency. Other code forms, ambiguous fields and incompatible flags are excluded, not inferred.
