## Base implementation closure

The preceding partial-recovery warning about the base implementation is superseded. `manifest-entries.json` and `UFortItemDefinition_NativeGetProfileKey.inc` propose the typed base virtual `FString NativeGetProfileKey() const`; the native name is assigned.
