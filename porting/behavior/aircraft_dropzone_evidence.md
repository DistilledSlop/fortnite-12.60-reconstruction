Static evidence from `/mnt/vibrato/fortnite-evidence/original-late-capture-1/image-125.runtime.bin` (SHA-256 `338c83a2314ccac1040a2c0bb520b893013cc7b58eda58e550da67f5d84de680`), addressed at VA minus `0x140000000`. Existing entry callback decompilation/disassembly is `porting/generated/callee_probe/blocking/0x1419520f0.{c,asm}`; lookup details are in `aircraft_lookup_evidence.md`.

## Entry callback

`AFortGameModeAthena::OnAircraftEnteredDropZone` body `0x1419520f0` casts its `+0x278` game state to AFortGameStateAthena. It does not check the cast result before dereferencing it. Starting with true, it visits every current `Aircrafts` index in ascending order, re-reading Num on each loop condition, and calls `GetAircraft(i)` even after the accumulator becomes false. Null results are ignored; a non-null result whose **entire byte** at aircraft `+0x2f0` is zero makes the accumulator false permanently. If the final accumulator remains true, including an empty array or all-null results, it calls `0x1419adfe0(GameState, false)`. The lookup's phase-sensitive logging and world/replay checks remain relevant.

Aircraft `+0x2f0` is not a reflected bool: AFortAthenaAircraft reflection puts `ClientFlightTimerDrift` at `+0x2ec` and `MiniMapIconScale` at `+0x2f4`; `bool_bits.json` has no aircraft bool at `+0x2f0`. The byte is therefore a native field in the gap, not the reflected `bIsOutOfPhaseAircraft`. Its writer, exact semantics and source name are not established. No claim that it is specifically a named drop-zone flag is supported by this read alone.

## Setter `0x1419adfe0`

The full function is `0x15c` bytes, ending in `ret` at `0x1419ae13b`. It takes AFortGameStateAthena `this` in RCX and a C++ bool in DL, returns void, and has no log calls. `bAircraftIsLocked` is reflected at `+0x1ef0`, mask `0x01` (`bool_bits.json`). The following statements describe the full control flow, including effects that must not be skipped:

1. Only when the old lock bit is set **and** the argument is false, assign the 32-bit sum of `PlayersLeft` (`+0x12f0`) and `PlayerBotsLeft` (`+0x1ecc`) to unreflected game-state `+0x1418`.
2. Call virtual `GetWorld` at vtable byte offset `+0x150`, then `0x14468fb70`. The latter builds an iterator from the world array at `+0x1c8` and initial index zero. Iterate in ascending order, re-reading its array length on each iteration. `0x142ee5dd0` resolves each weak object reference, returning null for invalid entries. The iterator shape matches UE's `FConstPlayerControllerIterator`; identifying the array specifically as `PlayerControllerList` still needs its world layout independently confirmed.
3. For each valid entry, cast to `AFortPlayerControllerAthena` (StaticClass `0x142a53450`; see `pawn_state_evidence.md`), read its controller `PlayerState` pointer at `+0x220`, and cast it to `AFortPlayerStateAthena` (StaticClass `0x142a8ae70`). On either failed cast, skip the entry. Call the player state's virtual `GetPlayerTeam()` at byte offset `+0x770`; if it returns non-null, call that team object's virtual at byte offset `+0x630` and store its int32 result in unreflected player-state `+0x1298`. Both AFortTeamInfo and AFortTeamInfoAthena point that slot to `0x141f60e80`, which returns `TeamMembers.Num()` (the TArray is at `+0x220` and its count at `+0x228`). Its original method name and the destination field meaning remain unknown. The call is virtual: substituting an unconditional direct array count would lose possible derived-class overrides.
4. After iteration, if `BroadcastSpectatorInfo` at game-state `+0x1ca8` is non-null, assign its `TotalNumPlayers` (`+0x218`) from `PlayersLeft` and `TotalNumTeams` (`+0x21c`) from `TeamsLeft` (`+0x1380`). Values are re-read after the iterator. There is no bot addition to the spectator player total.
5. Regardless of the transition, clear bit 0 in the 32-bit word at `+0x1ef0` and OR the zero-extended bool argument into it. No other effects are visible in this body. For ordinary C++ bool input this assigns `bAircraftIsLocked`, preserving other bits. Only an old-true/new-false transition performs steps 1–4.

Reflection identifies the source fields in steps 1 and 4, and `AFortBroadcastSpectatorInfo`'s two destination fields. Neither `+0x1418` in game state nor `+0x1298` in AFortPlayerStateAthena has a reflected property at that offset. Their native declarations and the virtual team-count contract need to be represented before proposing compilable code. The original calls GetWorld without a null guard and the iterator constructor derives an array address directly from that pointer; adding a guard would alter its contract.
