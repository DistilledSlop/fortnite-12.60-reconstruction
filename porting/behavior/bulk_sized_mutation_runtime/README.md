# Sized mutation recovery

Run `python3 porting/behavior/bulk_sized_mutation_runtime/scan.py`. It verifies the pinned original image and writes proposals and a report to `/tmp/gameplay-bulk-sized-mutation/`. This is the complete parameterless constant-mutation scan from `bulk_mutation_storage_runtime`, limited to cases where at least one class or parent size needs a GPSC fallback. It obtains each fallback directly from the unique original class registration target using `native_class_size_evidence_runtime/scan.py`'s exact registration-family extractor. Existing Bool sizes must agree with one another and with any extracted GPSC size; a disagreement aborts the scan. The report includes the extracted registration instructions and size source.

The original whole-body, flags, class identity, generated parent and declaration, class bounds, reflected and ported native occupancy, and proposed interval checks remain in force. The raw unsigned fields preserve whole-width writes; initialization and other writers are not inferred. The current scan proposes three AARDronePawn scaling mutations on one 32-bit field and USpatialFactionScreen's SetAboutScreenVisited on one byte field. The emitted files are proposals only.
