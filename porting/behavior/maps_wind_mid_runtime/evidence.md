# Wind MID helper contract

Review draft, not integrated or build verified. Captures are generated, git-ignored artifacts in `porting/generated/maps-wind-material-closure/_adhoc/`.

`0x141c0a630` takes actor, mesh, and 32-bit material slot. It calls the mesh virtual at 0x548 (GetMaterial). If the mesh equals actor+0x768 (StaticMeshComponent), it calls 0x141c058a0 with the material and one of actor+0x998 (state byte 1), actor+0x9a8 (state byte 2), or a static empty array (other states). This call occurs even if the material is null or the array is empty. The earlier recovery in `porting/behavior/building_materials51_runtime/` identifies 0x141c058a0 as the inlined IsDependent mapping loop. Its raw decompilation at `/tmp/building-materials51/probe/0x141c058a0.c` returns immediately for null input and iterates zero times for an empty array, so the draft’s null and empty checks preserve the result. For a non-null material, each matching original may replace the selection; after a selection differs from the input, a further replacement requires non-null override and the new original to depend on the previous original. The returned material, rather than the pre-mapping material, drives subsequent steps.

If the returned material is a MID whose outer is the actor, it is returned immediately, without SetMaterial. Otherwise, a MID with non-null Parent is unwrapped to that Parent; other materials, including null, are used directly. Native 0x144324750 creates a MID with that parent and actor outer. If unwrapped, 0x1443242c0 copies overrides from the original MID. The mesh virtual at 0x550 (SetMaterial) receives the same slot and new MID, which is returned. The existing generated `ABuildingSMActor.cpp` corroborates the operation names but is not independent binary evidence. UE4.25 `MaterialInstanceDynamic.cpp` defines Create and CopyParameterOverrides; Create accepts a null parent. No null mesh guard appears in this shared body.

`0x1442ad650` matches UE4.25 `UKismetMaterialLibrary::CreateDynamicMaterialInstance` in `Engine/Source/Runtime/Engine/Private/KismetMaterialLibrary.cpp`: null parent returns null; otherwise get the world from context with ReturnNull, use context as outer only when transient flag bit 0 is clear and world exists and (construction script running or world is not a game world), otherwise use null outer; call named MID Create and set RF_Transient when the selected outer is null. MID Create substitutes GetTransientPackage for null outer. Preserve name and flags rather than assuming the setup's omitted arguments.

Setup calls the mesh helper twice for each non-null mild slot, with an intense MID creation between them where the intense array index exists. Both calls and their material replacement side effects matter. The setup machine code at 0x141ddaf07 and 0x141ddb04a loads r8d from r12d for both mesh calls, so both receive the current loop slot. At 0x141ddaf9c–0x141ddafae, the intense call passes actor context, the intense array entry, NAME_None, and zero creation flags. It is still invoked when the selected entry is null, in which case it returns null.
