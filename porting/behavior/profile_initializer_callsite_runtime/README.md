# Profile initializer dispatch and argument lifetime

Original image and byte-window identities are in `evidence.json`. Ghidra decompilation was read-only with transaction rollback; Ghidra nevertheless changed project metadata/index files. No source integration or tests were performed.

Group routine `0x1410f0920` takes RCX = group, RDX = address of an FString-compatible ProfileId, R8 = profile class, R9D = flags. It scans the group's 32-byte entries at +0x128 using ASCII-case-insensitive string comparison. If a key is found and flag bit 0 is set it returns that entry's profile without initialization. Otherwise it creates a profile using `0x142ed7360` and dispatches its vtable +0x288 at `0x1410f0ac7` (new key) or `0x1410f0bc5` (existing key replacement). In both calls RCX = new profile, RDX = group, R8 = **the original incoming string address**, held in R14 since function entry. The return value of the initializer is ignored. Bit 1 of flags is stored in entry byte +0x19. The new-key branch copies the input to an independent temporary before creation and then copies that temporary into a new entry; the temporary's allocation is freed at `0x1410f0c0f`. It is never the value passed to the initializer. Replacement assigns the new object to entry +0x10 before dispatch; the new-key branch inserts it after dispatch.

Concrete upstream caller `0x141e5b450` constructs a stack FString via `0x142547b10`, which allocates/copies the NUL-terminated UTF-16 literal `campaign` (9 code units), calls group routine at `0x141e5b50e` with that FString address and flags zero, and frees its allocation at `0x141e5b520` after the group routine returns. The caller similarly constructs and frees a separate temporary for the preceding lookup. Neither the group routine nor the initializer consumes the incoming FString. The initializer copy-assigns it into profile +0xb0. Thus a source-equivalent declaration is `virtual void Initialize(UMcpProfileGroup* Group, const FString& ProfileId)` with group required non-null. ABI alone does not establish original spelling, source-level constness, or whether an additional compiler-created by-value copy existed at some other caller; this observed path supports borrowing and disfavours requiring a callee-owned by-value argument. The group routine's own source declaration and its profile class/flags naming remain provisional.

This resolves the dispatch and observed argument ownership; it does not resolve the native support object's exact source class and lifecycle, registry collection/lifetime, group representation, or full manager integration. Do not represent those as closed.
