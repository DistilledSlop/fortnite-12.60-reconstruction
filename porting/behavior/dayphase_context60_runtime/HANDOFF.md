# Context-aware time-of-day manager resolver

No source body is proposed: the actor-to-volume lookup at 0x141c7c5c0 has no recovered source equivalent and is essential to this resolver. In particular, `NativeFindVolumeAtLocation` is not a faithful replacement. The resolver's complete top-level control flow is recovered below; preserving the indirect component lookup and the actor selection semantics is required for a future implementation.

## Resolver 0x141f611f0

1. Obtain the context world using `GEngine->GetWorldFromContextObject(Context, EGetWorldErrorMode::LogAndReturnNull)` and its game state (0x141ef3ab0). Null context/world/game state or game state not `AFortGameStateBase` returns null immediately; this is not a volume lookup followed by a fallback in that case.
2. Resolve an `AFortVolumeManager` from the same context using 0x141c74820. The existing `AFortVolumeManager::NativeResolveVolumeManager` implements this: it uses the context world, requires `AFortGameStateAthena`, obtains its `VolumeManager`, and rejects an invalid manager.
3. If a volume manager exists, resolve a volume. If context is an `AActor`, call 0x141c7c5c0 (actor branch takes precedence). Else, if it is an `AFortPlayerState`, call 0x141c7d420, equivalent to existing `NativeFindPlayerVolume` (including validity check). Otherwise use a null volume. Player states are normally actors, but the native class-test order is still significant and must be preserved literally.
4. 0x141f9f270 returns null for null volume. Otherwise it calls the volume's virtual slot +0x610 with `UFortVolumeTimeOfDayComponent::StaticClass()` (0x142b39750). This is the virtual component-by-class lookup; do not replace it with a field read or a qualified/nonvirtual call. If the component exists and either its byte +0x130 bit 0 or byte +0xb0 is nonzero, return its pointer at +0x128, even if that pointer is null. Reflection order strongly identifies those as `bIsOverridingTimeOfDay`, `bUseEditorOverrideData`, and `TimeOfDayManager`, respectively; check the exact engine virtual declaration and native field offsets before using named source calls/fields.
5. If step 4 yields a nonnull manager, return it; otherwise return game state +0x2d0 (`AFortGameStateBase::FortTimeOfDayManager`, also exposed by `GetTimeOfDayManager()`). Null manager is allowed. Thus a component present but disabled, enabled with null manager, a missing manager, unsupported context, or no matched volume all use this fallback.

## Actor lookup dependency

0x141c7c5c0 accepts `(AFortVolumeManager*, AActor*)`, scopes `STAT_Find_Volume`, and requires a nonnull actor and a nonempty manager `VolumeObjects` (+0x278/+0x280). It computes actor bounds through virtual actor slot +0x548, with special handling for `ABuildingSMActor` via 0x141c07130 and a bounds box. For every nonnull volume except the context actor itself, it checks the volume's weak-object membership map; non-`AInfo` actors absent from that map require 0x141c6a510's geometric/overlap check. Eligible candidates are selected according to their bounds returned by 0x141c75610 (including floating-point comparisons and call ordering). If no candidate was selected and the actor is an `AInfo`, a guarded interface fallback uses interface class 0x142b39170, 0x142ec9900, and virtual interface slot +0x10. See the saved complete decompilation for exact branch and comparison ordering. This is considerably broader than the existing point-location helper and must be fully recovered, including 0x141c07130, 0x141c56eb0, 0x141c56e70, 0x141c6a510, 0x141c75610, and interface fallback identity, before a full source body is safe.

The existing player-volume helper was independently matched against 0x141c7d420 and 0x141c7d270; its own actor-pawn fallback uses the separately recovered point-location lookup. Probe outputs and hashes for the resolver, class identities, and examined dependencies are in `evidence/` and `native-evidence.json`. The resolver's assembly confirms the context argument remains in RCX for the initial world/game-state call. No canonical changes, tests, build, or runtime execution were made.
