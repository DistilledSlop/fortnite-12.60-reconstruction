# Common lazy image load guard: connected dependency

The prior candidate remains evidence only. The missing Slate object is now identified as `SLoadGuard`, not an arbitrary loading indicator. `UCommonLazyImage::RebuildWidget` at 0x1407ea310 constructs it with the original CommonLazyImage.cpp source location (binary string `SLoadGuard` at 0x1459f5d50), stores its 0x410-byte Slate instance in the shared pointer at `this + 0x2b0`, and passes an argument built from `this + 0x210` (the reflected `LoadingBackgroundBrush`) and a weak-object delegate. The construction helper is 0x1407a4070; the binary has other SLoadGuard construction sites at 0x1407ea866 and 0x1407eacd7. These are useful cross-references, not proof that their owning widgets have the same lifecycle.

`OnImageStreamingStarted` 0x1407d68a0 sets the guard's byte +0x408; on transition into loading, it sets +0x409, invokes 0x1407bc830 on +0x3e8 with true, and changes visibility on the children at +0x3b8 and +0x3c8. `OnImageStreamingComplete` 0x1407d6840 and `CancelImageStreaming` 0x1407ade90 clear +0x408 and call 0x1408033f0. That updater derives the displayed state from (+0x3f8 != null) OR +0x408, only updating the delegate and both child visibilities on a state change. Thus it would be wrong to substitute a boolean-only callback or hide the indicator unconditionally on completion. The other source of loading and exact Slate construction, child layout, visibility values, delegate binding, synchronization and release lifecycle still need recovery.

Null restoration helper 0x1407fb3e0 obtains the CommonUI settings object by calling 0x1407c5060, then reads DefaultImageResourceObjectInstance at settings +0xb0. The getter uses FModuleManager::GetModule off the game thread, LoadModule on the game thread, and module virtual +0x50; that slot is 0x140680310 (return module +8). It is not a style-registry or FSlateBrush call. The CommonUI module constructs and roots a real UCommonUISettings instance, optionally initializing its configured resources. See ../commonui_module_brush_runtime/RECOVERY.md. Material resources clear the texture parameter name and call the base material setter; other resources use the overridden texture setter (texture cast or null, match-size false).

Source policy: do not promote SetBrushFromLazyDisplayAsset until SLoadGuard construction, both loading sources, exact visibility/delegate behavior and resource release are connected, along with texture/material overrides. Do not use synchronous loads, a blank replacement brush, or invented Slate hooks. `UImage::RequestAsyncLoad` already provides cancel, immediate loaded dispatch, and guarded async completion as described in the prior recovery note.
