# Connected CommonLazyImage runtime

This directory supplies executable source for the connected UCommonLazyImage path, including its SLoadGuard Slate object. Source aliases replace private original method/delegate names. `original-policy.json` pins the original reflected class/fields and native exec records and nineteen bounded mapped-image windows; validation uses `pread`, never a whole-image read or hash.

## Generator integration

Load `policy.py`. Before any output is written, call `validate_source(image_path)` and `validate_classes(blocks_by_va, name_to_block, guarded_native_execs)`. Pass the owner-specific native exec dictionary to `apply(model, block, owner_fns, native_execs)` during model construction. Append `declarations(model)` to the generated class and `definitions(model)` to its cpp. Add `sources(blocks, names)` to CommonUI's generated source set and validate the fully rendered header/cpp with `validate_output`. The model adds three original reflected callables and supplies their implementations; it does not claim recovered implementations of the separate LazyTexture/LazyMaterial callables.

Do not manually edit generated Native output. Root owns generation, promotion and the coherent client build/affected flow validation batch.

## Recovered contracts

* Constructor 0x1407971d0 initializes the default brush and then sets DrawAs to NoDrawType. The reflected native fields are unchanged.
* Rebuild 0x1407ea310 constructs SLoadGuard with a pointer to the actual LoadingBackgroundBrush, a weak UObject state delegate to 0x1407c9d50, and a virtual image construction hook at +0x320 (0x1407e63b0 calls UImage::RebuildWidget). State callback only broadcasts BP_OnLoadingStateChanged.
* +0x298 (0x1407fe0e0) forwards UImage::SynchronizeProperties. +0x2b0 (0x1407e02d0) is **OnWidgetRebuilt**, not SynchronizeProperties: after the base hook it derives forced loading from StreamingHandle existence, !HasLoadCompleted and !WasCanceled. This distinction follows UWidget::TakeWidget's synchronization/OnWidgetRebuilt sequence.
* Release 0x1407eec10 releases the base SImage and resets the SLoadGuard shared pointer. The Slate destructor 0x14079af80 releases the shared streamable handle and child references; it does not explicitly cancel the Slate request. CancelImageStreaming does call the base image cancellation before clearing forced loading.
* SLoadGuard construction 0x1407b2af0 builds SOverlay with content SBorder then loading SBorder. Content uses zero padding and null border brush. Loading uses zero padding, center/center alignment and the supplied background brush; its SScaleBox uses ScaleToFit/DownOnly and fill/fill alignment. Inside is SHorizontalBox with an AutoWidth image slot and a FillWidth(1) text slot, both left/center aligned. The SImage uses the real settings DefaultThrobberBrush; default loading text is empty. There is no circular throbber.
* This Slate argument surface deliberately covers the CommonLazyImage callsite defaults. UCommonLoadGuard's separately configured LoadingText/TextStyle/ThrobberPadding/ThrobberAlignment callsites are not promoted by this component. The two real loading sources and their state semantics are shared.
* Slate state +0x408 is the forced loading source; +0x3f8 is a real FStreamableHandle; +0x409 is the displayed state. Updater 0x1408033f0 computes handle existence OR forced loading, firing the delegate only on transitions and **before** changing child visibility. Content/loading alternate SelfHitTestInvisible (0x11) and Collapsed (0x02). It does not use Hidden or HitTestInvisible. Both children have these exact initial visibilities.
* The second source's typed producer 0x1407c5c00 accepts a soft UObject and a UClass callback. A changed soft path cancels/releases the previous handle. It stores the new soft pointer, immediately calls back for an already resolved UClass, otherwise requests only a changed non-null path using priority 100 and unmanaged/nonstalled arguments. Callback 0x14079e8e0 checks weak Slate lifetime, reads the guard's current soft object, and only on UClass success releases the handle, updates state, then invokes the callback. A failure/nonclass result retains the handle and produces no callback. A repeated unresolved path does not issue a duplicate load. No synchronous loads or substitute assets are introduced.
* Texture setter 0x1407f5b10 services both texture virtuals through a shared UTexture path. When MaterialTextureParamName is set and GetDynamicMaterial succeeds, set its parameter and optionally write Brush.ImageSize for UTexture2DDynamic or UTexture2D; this branch does not call the image setters. Otherwise dynamic textures use base SetBrushFromTextureDynamic with match-size **false**, and UTexture2D/null uses base SetBrushFromTexture with the caller's bool. SetBrush/SetBrushFromAsset clear the parameter after base calls; material setter clears it before. SetMaterialTextureParamName only changes it when Brush currently contains a material.
* SetBrushFromLazyDisplayAsset 0x1407f5850 restores settings DefaultImageResourceObjectInstance for a null path, selecting material or texture/null and match-size false. Otherwise UImage::RequestAsyncLoad supplies cancellation, immediate loaded dispatch, weak-image/current-path completion guard and streaming hooks. The callback 0x14079e640 dispatches virtual texture or material setters, with no setter on failed/unsupported objects. No C++ default boolean or Blueprint metadata default is inferred from exec initialization.

## Validation boundary

Policy/source checks are read-only and may be included in root's single integration batch. This directory does not alter Engine, generator or Native files and does not independently run a client build. The configured CommonUI settings/module provider is a dependency already integrated by root.
