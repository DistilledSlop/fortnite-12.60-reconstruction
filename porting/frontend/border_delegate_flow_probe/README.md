# Border and delegate GUI diagnostic

Copy `BorderDelegateFlowProbe.h` and `.cpp` into `Source/FortniteGame/`, invoke `RegisterBorderDelegateFlowProbeDriver()` from startup, and launch a GUI client with `-BorderDelegateFlowProbe`. The driver waits for a game world and player controller, emits `BORDERDELEGATEFLOW` rows, and exits with failure on a failed observation or timeout. Run `python3 verify.py RUNTIME_LOG` to require all twelve successful rows exactly once and in order. It reports whether the actual Slate game viewport had an interface.

The probe creates a controlled player-owned `UCommonBorder`, checks its default DrawAs and visibility, builds real Slate via `TakeWidget`, copies a test style CDO's brush, and tests same, null and incompatible class setters with an override counting virtual synchronization. The incompatible class is passed through `TSubclassOf`, whose checked getter returns null; the test does not assert the internal raw pointer. It uses an empty Slate border's desired size to observe inherited parent padding and safe-zone minimum clamping. When no game viewport interface is available the expected safe margin is zero; otherwise it measures against the actual safe margin and does not claim to have exercised the zero-margin fallback. The modified style CDO is restored.

It looks up the standalone `/Script/CommonUI.CommonActionCommited__DelegateSignature` (original spelling: one t in Commited) and checks single-cast delegate, one bool Parm|OutParm without ReferenceParm, and no return. It also checks the `UFortKismetLibrary.IsMobileGame` WorldContextObject and bool-return reflection shape and a false result for the current world. These are controlled diagnostic observations, not callback behavior, original-runtime comparison, pixel validation or full safe-zone lifecycle coverage. No build or runtime pass is claimed until integration and execution.
