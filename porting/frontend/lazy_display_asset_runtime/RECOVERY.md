# UCommonLazyImage::SetBrushFromLazyDisplayAsset recovery

Reflection (`porting/generated/reflection/native_funcs.json`) records `LazyObject` as a const-reference soft UObject property and `bMatchTextureSize` as a bool, with callable function flags 0x4420401. The exec thunk at 0x140810ab0 initializes its temporary bool to false and calls the native function at 0x1407f5850. This is not sufficient evidence of a C++ default argument or Blueprint metadata default.

The native function tests whether the soft object path is null. For a null path, it calls 0x1407fb3e0, which obtains a brush through a `CommonUI` style lookup (the exact style/brush identity is not yet established), then reads its resource and restores it: a material clears the texture parameter name and calls the base material setter; otherwise it passes a UTexture2D cast (or null) to the overridden texture setter with match-size false. The precise behavior also depends on the overridden texture setter, described below.

For a non-null path, it captures a weak `this`, a copy of the soft object, and `bMatchTextureSize`, and calls `UImage::RequestAsyncLoad` with that soft object and callback. The callback at 0x14079e640 first resolves the weak image; it resolves the soft object and calls virtual `SetBrushFromTexture(UTexture2D*, bool)` for a UTexture2D, or `SetBrushFromMaterial(UMaterialInterface*)` for a UMaterialInterface. Other types and failed resolutions cause no setter call. The boolean is passed to the texture setter only.

The binary helper at 0x143d84c20 is the function overload wrapping the callback in a streamable delegate; its virtual dispatch at +0x300 reaches the corresponding engine request overload. Compare `/opt/fortnite/UnrealEngine/Engine/Source/Runtime/UMG/Private/Components/Image.cpp:268`: it cancels previous image streaming, calls the delegate immediately if already loaded, otherwise calls the streaming-start hook and requests an async load at high priority. The completion callback uses a weak image and checks that the current path still matches before invoking the captured callback and streaming-complete hook.

No candidate source is supplied yet. The generated class lacks the original overrides for texture/material setters and streaming hooks. In particular 0x1407f5b10 implements the texture setter: when `MaterialTextureParamName` is set and a dynamic material is available, it sets the texture parameter and optionally updates brush size, otherwise it chooses the appropriate base setter. The null-path default restoration and asynchronous callback both dispatch into these missing overrides. Restoring only the reflected callable with base behavior would lose connected behavior and is not justified by this evidence. The loading state transitions and full override implementations remain to be recovered.

The original vtable at 0x1459f59b8 maps +0x2d0 and +0x2e0 to the shared texture setter (0x1407f5b00 -> 0x1407f5b10), +0x2e8 to the material setter (0x1407f5ae0), +0x308 to cancellation (0x1407ade90), +0x310 to streaming start (0x1407d68a0), and +0x318 to streaming completion (0x1407d6840). The material setter clears `MaterialTextureParamName` and forwards to the base UImage setter. Cancellation and completion clear byte +0x408 of a non-reflected Slate object at `this + 0x2b0` and call 0x1408033f0; start sets that byte, checks/sets byte +0x409, and triggers further Slate behavior. That load-guard object's identity and lifecycle must be reconstructed before these hooks can be faithfully restored. The binary also clears `MaterialTextureParamName` following the base `SetBrush` and `SetBrushFromAsset` calls (vtable +0x2c0 and +0x2c8).
