# CommonInput module startup evidence

The direct registration of the name `CommonInput` to factory `14081bef0` remains **unproven**. The getter `1407c4fc0` looks up that name and invokes vtable +0x40; the factory installs vtable `145a0db48` whose +0x40 returns its +8 field. This is a consistent structural match, not a recovered registration edge. Do not present it as proven or invent a module identity. Factory details and shutdown are in `../common_input_settings_evidence/HANDOFF.md`.

Startup slot +8 (`14081d150`) calls the settings class getter `14081df50`, then calls pointer getter `142e80820` and preserves its result as the outer. It initializes the FName argument to zero and calls the constructor-context check with the original `NewObject with empty name ...` diagnostic before calling `142ed7360`. On the Windows x64 calling convention the arguments at that call are class, outer, zero name, zero object flags, zero internal flags, null template, false copy-transients, null instance graph, false assume-template-archetype. The entry to `142ed7360` uses the matching register and stack argument positions and forwards the first five arguments to object allocation. This matches the older overload of `StaticConstructObject_Internal` in local UE 4.26 `Engine/Source/Runtime/CoreUObject/Public/UObject/UObjectGlobals.h:321`; that version's `NewObject` diagnostic and defaults are in the same header. It then stores the returned object at module +8 and adds the object-array root flag. The precise original source overload is not distinguishable from this evidence.

`142e80820` returns one global pointer. This is consistent with `GetTransientPackage()` (the local UE implementation returns `GObjTransientPkg`), and the zero defaults are consistent with `NewObject<UCommonInputSettings>()`, but the global's identity has not been independently established. Avoid claiming the transient outer as proven or replacing the created object with the settings class default object. Lifecycle and linkage need to be recovered before integrating a production module implementation.
