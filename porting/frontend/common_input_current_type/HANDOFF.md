# CommonInput current-type getter candidate

This isolated policy candidate adds the reflected const, BlueprintCallable, BlueprintPure `ECommonInputType GetCurrentInputType() const`, implemented by returning the existing mutable `CurrentInputType` field. It does not create an input producer or claim complete input routing. Existing constructor initialization and all producers, state transitions, and event broadcasting remain outside this proof; whatever value exists in the field is returned, including unrecognized byte values.

Original reflection identifies owner block `0x145a0e0d0`, owner construct `0x14081e010`, package `/Script/CommonInput`, create function `0x14081e070`, native exec `0x14081ef40`, flags `0x54020401`, and a single enum return property with flags `0x10000000000580` and enum construct `0x14081ee20`. The underlying field is reflected enum `CurrentInputType`, original offset `0x79`, with the same enum construct and transient property flags `0x40000000002000`. The enum metadata records MouseAndKeyboard=0, Gamepad=1, Touch=2, Count=3.

The original native exec at `0x14081ef40` performs normal frame advancement, calls `0x14081b540` and stores AL to the return byte. The helper is exactly `movzx eax, byte ptr [rcx + 0x79]; ret`. The create function uses the standard lazy construction pattern. `replay.py` checks those exact instruction bytes, full image SHA-256, and the reflected function, native registration, field, and enum records; this establishes static evidence, not runtime execution of the original.

`policy.apply` guards the owner, reflected function, property and underlying-byte metadata, emitted enum field declaration, exact native registration, and declaration collisions. `validate_types` guards the exact enum record and type availability; the integration must call it before applying this policy and must pass the `UCommonInputSubsystem` entry from `native_funcs.json` as `native_execs`. Append `definitions(model)` to emitted C++ definitions, and preserve the normal generator's reflected declaration for the injected model function. No source generator integration is included here. Check that the enum is already in the generator type closure (it is required by the existing reflected field). No original layout offset is imposed on generated C++.

Validation: `python3 porting/frontend/common_input_current_type/replay.py` and `python3 porting/frontend/common_input_current_type/test_policy.py` pass. The latter compiles the actual definition in a standalone C++ shim and checks all 256 successive mutations, including all named enum values; it also checks guard rejection. It is not a UE/UHT build or an integrated runtime test.
