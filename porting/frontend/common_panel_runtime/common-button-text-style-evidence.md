# CommonButton text-style selector core

This is a portable decision core only; it is not registered, generated, staged, or wired into a UObject. The selected bit and its transition producers are not yet integrated. A constant false selected callback would lose reachable selected styles and must not be used as integration. The owner and candidate callbacks also remain to be implemented against the runtime's actual types and validated before registration.

The pinned original image and nine instruction spans are recorded as SHA-256 metadata in the companion JSON. Selector `0x1407c2170` resolves the typed style CDO first, then reads enabled; disabled tries `+0x4b8`, while enabled reads selection bit `+0x2a1 & 1`, then tries selected-hovered `+0x4b0` and selected `+0x4a8`. Remaining paths call hover and try normal-hovered `+0x4a0`, then normal `+0x498`. Hover can be called twice. Getter `0x1407c2550` returns the chosen CDO's actual class, and exec `0x14080a6c0` exposes it as a class return.

The original reflection's CommonButtonStyle block `0x145a007f0` independently identifies offsets `0x498`, `0x4a0`, `0x4a8`, `0x4b0`, and `0x4b8` as NormalTextStyle, NormalHoveredTextStyle, SelectedTextStyle, SelectedHoveredTextStyle, and DisabledTextStyle respectively, all Class properties with meta-class `0x1408131c0`. The evidence test binds this block through native_class_index and checks the original reflection properties, getter signature, image hash and instruction spans.

The portable callback `TryCandidate` represents the candidate-specific validation sequence, not merely a field read: the original checks the field, resolves the text-style type, rereads and validates the class, resolves the type again, rereads/revalidates the class and reads its CDO, then validates the CDO's actual class. A future runtime adapter must preserve those operations and their order, including any consequences of state changes during callbacks. The tests here verify decision and callback order, lazy candidate attempts, null/invalid outcomes represented by a null callback result, reentrant state changes, and return of the CDO's actual class; they do not execute the original machine code or verify that future adapter. No full CommonButton parity or UE runtime behavior is claimed.

Run `python3 porting/frontend/common_panel_runtime/test_button_text_style_core.py` from the repository root. The evidence test requires the pinned original image at `/mnt/vibrato/fortnite-evidence/original-late-capture-1/image-125.runtime.bin` and the generated reflection inputs.
