# CommonButton base selection notifications

These source aliases implement the original +0x4b0 and +0x4b8 base virtuals. Each calls its BP event, optionally broadcasts the shared native +0xb50 multicast and the dynamic OnSelectedChanged(this, state), and then makes a fresh virtual call to the already shared +0x4f0 NativeOnCurrentTextStyleChanged. This is synchronous and can reenter at every callback. The native one-bool multicast's reverse traversal, locking, and invalid-entry compaction are visible in original 0x1406934e0; it is not a singlecast. All native producers must share NativeSelectedChanged. Source aliases do not assert binary vtable layout parity.

The original property metadata identifies OnSelectedChanged at +0x2d8 and its exact signature; the generated header has Button followed by Selected, although the original reflection property table lists them in reverse. Original event global initialization binds BP_OnSelected, BP_OnDeselected, and OnCurrentTextStyleChanged; style runtime owns the final virtual. See `/mnt/vibrato/fortnite-work/common-button-{selected-transition-contract-1,style-refresh-contract-1}/HANDOFF.md` and `common-button-internal-binding-1/HANDOFF.md`. Original 0x1406934e0 increments the lock, iterates +8 count backwards, invokes each valid delegate with the bool, and calls compaction 0x140685370 on expired entries.

Generator integration must run validate_classes against complete original delegates, apply after style-rebuild policy, include declarations and definitions, and validate_output on the fully rendered headers before writes. Add the authentic BP_OnDeselected event tuple `('UCommonButton', 'BP_OnDeselected', '0x140805cb0', '0x140806770', 0x08080800, 'protected')` to the generator. Do not register these aliases as selection transitions or Initialize. Neither a build nor UE runtime verification has been run for this candidate.
