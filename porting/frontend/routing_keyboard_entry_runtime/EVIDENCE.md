# Original physical input entry: partial recovery

Mapped image `/mnt/vibrato/fortnite-evidence/original-late-capture-1/image-125.runtime.bin`, base `0x140000000`. The PE has executable `.text` sections `[140001000,1458fbc00)` and `[148d2c000,149e4d600)`; the high addresses below are executable, not data. Reads were bounded seeks in 1 MiB chunks, with bounded disassembly windows.

Scanning for direct rel32 call and jump targets to `1407e3b40` found four calls in executable sections: `1407c9aab` and `1407c9be9` (analog cursor), and `1451567d4` and `145156b99`. No direct rel32 jump to that target or absolute 64-bit pointer to it was found. This does not exclude inlining or indirect addressing. The analog cursor's key eligibility `1407cffa0` requires input method byte `+d4 == 1`, so it cannot supply ordinary keyboard entry.

It scans an array at owner `+58`, stride `0x18`, comparing each first object's `+b8` controller id. It resolves `UCommonUIActionRouter` from that object through `14078c710`, and calls `1407e3b40` with the passed key and event. After a player entry matches, it assigns an unhandled reply before router lookup; without a match it leaves the reply unchanged. Router result `0` assigns handled; `2` leaves the reply unhandled. Result `1` enters the controller-specific continuation at `1451567e1`, potentially copies a reply from `14236ad20`, checks a predicate from `14238ead0`, and can assign handled. The owner is UFortUIManager; the first object is UFortLocalPlayer and the entry is FFortRootViewportLayoutInfo. The other object is the root UUserWidget; helper 144ade750 casts its GetOwningPlayer to AFortPlayerController. The controller continuation is not yet closed. This is not an unconditional pass-through.

It converts touch event zero to pressed, value 5 to released and other nonzero values to repeat, calls `1407e3b40`, and treats result 2 specially. Its full downstream path remains unclosed.
