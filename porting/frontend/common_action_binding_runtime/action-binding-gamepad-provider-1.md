# Action binding gamepad provider: original-image contract

Static proof only, no native files changed or runtime tests. Replay: `python3 /mnt/vibrato/fortnite-work/action-binding-gamepad-provider-1/replay.py` → `PASS nine original-image windows and both class literals`. Image: `/mnt/vibrato/fortnite-evidence/original-late-capture-1/image-125.runtime.bin`, base 0x140000000; prior constructor proof `/mnt/vibrato/fortnite-work/action-binding-record-constructor-1/`.

Legacy branch evaluation, after row resolution, text assignment, keyboard processing and touch processing:

1. Call Owner's vtable slot +0x290, `UUserWidget::GetOwningLocalPlayer()`. Owner is an actual widget object; null or wrong object cannot satisfy the virtual call. The virtual can return null. Its identity is corroborated by `confirmation-interface-contract-1/HANDOFF.md` and UE `UMG/Public/Blueprint/UserWidget.h:334`.
2. Set router to null first (r12 zeroed at 0x1407957e8 and not reassigned on legacy path before 0x140795c1b). If the local player is nonnull, call 0x14078c710 on it. That helper performs a typed lookup for `CommonUIActionRouter` in its subsystem collection at +0xd8 and returns a type-checked result or null. Class getter 0x1408132b0 uses the pinned UTF-16 class literal at 0x145a08ae2. This is a router lookup, not a local-player lookup as the earlier constructor handoff loosely called it.
3. Regardless of whether router is null, call 0x1407c3b10(router). Its very first body access is `[router+0x20]`: the UObject Outer, expected to be the router's local player. The helper uses that actual outer's collection at +0xd8 and performs the same typed lookup for `CommonInputSubsystem`, whose class getter 0x14081de90 uses literal at 0x145a0e4da. It returns a type-checked result or null. The second player is derived from the router's Outer; there is no second call to Owner or explicit equality check with the first player.
4. Regardless of lookup result, call 0x14081b530(subsystem), which reads byte `[subsystem+0x7a]`. At 0x140795c38 the return byte is **zero extended** to unsigned 0..255; at 0x140795c3b it is multiplied by 0xa8 and applied to row +0xe0 for the gamepad info. There is no index comparison or clamp. Four reflected gamepad elements therefore require an in-range 0..3 value for valid row access, but original execution does not enforce that bound here. No current-input-type test or alternate element is used.

A null local player, missing/wrong-type router, null router Outer, or missing/wrong-type input subsystem cannot produce a meaningful default: steps 3/4 dereference unconditionally. Null subsystem collection results are allowed by the lookup helpers but not by this consumer. A missing router and null initial player both reach the router +0x20 access; a missing CommonInput reaches its +0x7a getter. The code contains no fallback to player zero, index zero, other input device, or silent omission. Treat these as caller/lifecycle preconditions; a deliberate diagnostic failure in a reconstructed caller must not be described as an original graceful fallback.

Both typed lookup helpers perform class checks before and after 0x14460d300. The latter matches `FSubsystemCollectionBase::GetSubsystemInternal` in `/opt/fortnite/UnrealEngine/Engine/Source/Runtime/Engine/Private/Subsystems/SubsystemCollection.cpp:49`: first class-key map lookup, then the first matching subsystem from the type array if the map misses, else null. They do not allocate a substitute subsystem. Generic UE templated collection lookup uses a cast (`Engine/Public/Subsystems/SubsystemCollection.h:81`). Exact initialization and population lifecycle is outside this proof.

Relevant original disassembly can be replayed without exporting the image: `objdump -D -b binary -m i386:x86-64 -M intel --adjust-vma=0x140000000 --start-address=0x140795c0b --stop-address=0x140795c50 /mnt/vibrato/fortnite-evidence/original-late-capture-1/image-125.runtime.bin`; change window to 0x14078c710..0x14078c7a2, 0x1407c3b10..0x1407c3ba3, or 0x14460d300..0x14460d385 for the two lookup helpers and collection lookup. Replay verifies original bytes, it does not execute these paths or independently prove UE source equivalence.

Integration still requires production router/subsystem availability and actual instance/lifecycle wiring, and test coverage of ordinary, missing and out-of-range conditions. In particular, no type-safe implementation may bypass the router or silently clamp the enum while claiming this proof. Original helper observations do not establish how the router is initialized or whether every possible runtime Outer is a local player.
