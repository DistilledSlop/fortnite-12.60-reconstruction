# Native Blueprint super-import inventory

`NativeSuperImportProbe` reads only CUE4Parse's legacy package import/export tables. It never calls `GetExports`, dereferences a lazy export, executes scripts, or invokes native game code. It requires the fixed closure manifest's 721 unique `.uasset` paths, verifies each header's SHA-256 against that manifest, rejects unsafe paths, and writes a new report without overwriting existing evidence. The report records manifest, 721 headers, isolated tool binary and CUE assembly hashes. Native targets are retained only when a Function export's imported `SuperIndex` resolves through a three-element `/Script/package`, class, function import chain. Invalid, cyclic, export-outer, and non-native chains are reported separately.

Build the standalone project against the already-built CUE inspection dependencies, then run:

```sh
dotnet build porting/frontend/native_super_import_probe/NativeSuperImportProbe.csproj -c Release
# Use a new report name for each run.
dotnet porting/frontend/native_super_import_probe/bin/Release/net10.0/NativeSuperImportProbe.dll \
  porting/generated/frontend-probes/closure-fixed \
  porting/generated/frontend-probes/runtime-fixed-manifest.json \
  porting/generated/frontend-probes/native-super-imports-NEW.json
python3 porting/frontend/native_super_import_probe/classify.py \
  porting/generated/frontend-probes/native-super-imports-NEW.json \
  porting/generated/frontend-probes/native-super-classification-NEW.json
```

The classifier matches the target package and exact C++ owner, then selects original function metadata by that owner's construction-function identity. It reports access bits, flags, full decoded serialized property records, and whether the currently selected source header contains that function name. Header name presence alone does not establish UHT flags or behavior. Ambiguous owners, joins, flags, or parameters fail closed; Native functions are separately identified as requiring behavior. UMG's actual engine `UserWidget.h` is checked directly. No event implementation or declaration is generated by this tool.

The source-derived run `native-super-imports-3.json` has 721 package headers, 9,221 exports, 259 Function exports, 102 imported function supers, 43 distinct native targets, and no malformed import chains. Its SHA-256 is `7b7fd855ad6ca013ea672bf6fc2682cdf8f0f19d8bf5db5dad29d946d831bc5d`; `native-super-classification-5.json` is `d1f52958f1ae6436c8827ea949276edb0aaeb6169b615cd5365b5604f9bd09cc`. Its 41 non-Native BlueprintEvent classifications and two Native functions reflect the frozen input snapshot, not a complete analysis of arbitrary packages. Root/Login runtime testing and exact UHT registration are still needed for any resulting declarations.

Run `dotnet .../NativeSuperImportProbe.dll --self-test` for five chain guards and `python3 porting/frontend/native_super_import_probe/test_classify.py` for the portable classifier tests.
