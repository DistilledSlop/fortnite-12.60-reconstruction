# Profile snapshot and pawn tag family

Nine complete original bodies extend the existing typed profile backend and restore the pawn gameplay-tag interface. The canonical ASC getter is reused. Independent review validated all 41 evidence hashes and twelve getter tables. The faction getter names its typed profile local so generation resolves the full class header. UE build/runtime verification is pending.

## Original contracts preserved

* Base backend +0x30, 0x1410fe3c0, calls Empty(0), directly searches its existing Groups+0x58 via canonical NativeFindProfileGroup, then copies the ordered shared-pointer array if found. It must not call virtual +0x28.
* Overlay backend +0x30, 0x1410fe440, calls Reset(0), retaining allocation, then dynamically calls its backend +0x28 query and copies the returned ordered group. Direct image disassembly distinguishes clear helpers: 0x1407bb0e0 always resizes to requested zero capacity, while 0x140fb93a0 keeps capacity when sufficient. These are intentionally different.
* Wrapper 0x1410fe490 dispatches actual NativeBackend virtual +0x30. No fallback, new map, eager backend, or null-success case. The original installed/live backend precondition is retained. Installation, owner lifecycle, and GC are not additional source gates for these bodies.
* Faction getter 0x141b46360 preserves lazy initialization, ordered PlayerTech snapshot, record ItemObject+0x88, account-item class filter, virtual IsFavorite(), and first matching item's result even if invalid. Snapshot references die before ASC mutation. String copy and length-taking FName constructor preserve the original FString length, including embedded NULs: helpers 0x142ba6a50/0x142cd48a0 correspond to `FName(TemplateIdCopy.Len(), *TemplateIdCopy, FNAME_Add)`; local Core NameTypes.h exposes this constructor and UnrealNames.cpp passes the explicit length to MakeUnconvertedView/MakeDetectNumber.
* Both original Warning diagnostics are present with exact strings and category LogFortControllerComponent_PerkSystem. Original initializer 0x14028ef40 references UTF-16 category name 0x145ee3d70 and initializes category object 0x14811c230 with default Log (5), compile-time All (7). This is a single emitted static support header, matching existing SharedProfileSysLog support convention.
* Canonical ASC helper 0x141b462b0 matches direct disassembly: cast owner PC, cast its PlayerState, virtually call the state ability interface, otherwise null. It has no omitted diagnostics. Faction getter sets explicit count to one only after uncached initialization succeeds; `SetLooseGameplayTagCount` delegates to SetTagMapCount/SetTagCount, preserving original delta semantics without adding ASC OnTagUpdated dispatch.
* Base pawn getter 0x1423233c0 resets output before virtual GetAbilitySystemComponent and ASC owned-tag dispatch. Athena 0x141a14f80 calls that base, then on authority obtains PC PerkSystem through virtual FindComponentByClass, resolves faction, and appends a valid tag. The engine's three predicate methods are virtual defaults, not pure; preserving the original base predicates is necessary because those originals call ASC directly (never Athena's extra faction result), including HasAll(empty)==false without an ASC.

## Invoked getter family closed

`getter-inventory.json` covers all twelve reflected AFortPawn classes from pinned class_parent_map. Eleven prior constructor identities were reused; AFortAIBuddy's previously missing constructor was resolved locally: GPSC 0x142790070 installs native thunk 0x142790a00, which tail-calls ctor 0x1422b5db0. Its stores prove primary table 0x14610da00 and tag-interface table 0x14610e978 at original pawn+0x4b0. This table's +0x10 getter is base 0x1423233c0. Corresponding disassembly is retained here.

Eight classes use base getter: AIBuddy, AIPawn, BotPawn, Pawn, FeedbackAnnouncer, InteractablePawn, Taker, PlayerPawn. Four use Athena getter: PlayerPawnAthena, CharacterVehicle, CharacterVehicle_Ostrich, RemoteControlledPawnAthena; these all inherit Athena in the pinned chain, so no additional override bodies/declarations are needed. The same table reads show the three original base predicates in all twelve classes. This is the invoked native getter family, not a broad inventory of unrelated pawn virtuals or Blueprint runtime objects; real interface virtual dispatch preserves descendant behavior.

No genuine missing effect remains in this bounded profile/tag payload. It does not claim whole backend lifecycle or prediction/runtime completion.
