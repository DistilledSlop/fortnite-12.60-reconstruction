# Time-of-day context predicate

`0x141ed8de0(ContextObject, GameMode)` returns whether the byte selected by the already canonical `UFortGameInstance::NativeGetGameMode141ed4e30(ContextObject)` equals the incoming byte. The proposed address-alias helper delegates to that function; no guessed enum restriction is imposed. In particular, the spawn call `(nullptr, 0)` is true exactly when the fallback manager byte is zero. When the engine or its asset manager is missing the fallback byte is 2, so this call is false. If a nonnull context is passed, both native routines call the same world lookup without first checking GEngine, then inspect the world's owning game instance and its class, before falling back. The canonical helper preserves those semantics and the checked asset manager lookup. See `../building_init_mode_helpers_runtime/README.md` and `../asset_load_callback_runtime/NativeGetGameSubMode.inc` for the provider and field bindings; do not create duplicate state.
