# Asset load suppression predicate

This is a proposed actual-source port of 0x141e04570 and phase accessors 0x141ed7750 and 0x141dfb870. Names and placement on UFortAssetManager are assigned. The controller type is a partial logical representation of the *same* actual GI-owned shared object at +0x650; its bIsShown corresponds to object+0x40. The original allocates and installs it during GI Init. That construction and the full show/hide lifecycle are **not yet ported**: do not treat the empty shared pointer in an unextended generated GI as original behavior. Future work must extend this same type and initialize the same member, including original side effects, rather than add a parallel flag. Phase initialization and writers are also open; no initial phase value is invented. Original enum values are documented in ../asset_loading_predicate_runtime/HANDOFF.md; the accessor keeps the raw byte to preserve values above 4.

The predicate uses engine virtual IsInitialized, context World and OwningGameInstance, IsGameWorld, direct DemoNetDriver checkpoint flag, the frontend game-mode exclusion, a weak pin of the GI strong member, and AND across qualifying contexts. Null/failed pin leaves the accumulator unchanged. The support type does not promise native layout. source_policy.py validates raw image windows and provides the header; generator integration is still required. No canonical edits, builds or tests were made. Engine header access to the checkpoint flag and generator acceptance remain to be verified during integration.
