# Conditional base movement-speed admission

Six complete candidate bodies from `behavior/movement_speed64_runtime` are proposed: base movement component `GetMaxSpeed`, four pawn speed virtual targets, and pawn jump horizontal override. The bodies are copied unchanged apart from a confidence comment. The shared math header remains at the candidate path. No Athena component override or native penalty fields are proposed. The existing movement-max-acceleration policy owns the movement-style helper and must execute first so that +0x998 remains virtual.

Integration must merge `manifest-entries.proposed.json` as one family, call `validate_required_classes` at full class-list validation, call `apply` after existing movement-max-acceleration `apply` and before rendering, and call `finalize` after render. Explicit includes are added by `apply`: the manifest engine-header validator rejects generated headers and the math header. The math header relative path assumes the normal `porting/native/Source/FortniteGame/Generated` destination. `test_generator_admission.py` overlays the family and runs the actual generator to completion of these five classes in `generated/agents/base-movement-admission80`; it does not compile or execute the result.

This is conditional source preparation, not runtime acceptance. Athena currently inherits the base component override: it gains these base branches but omits its original jump/melee penalties and flying multiplier until its full override and penalty lifecycle are restored. Missing movement attribute producers, air state writers, and other dependencies can change runtime behavior. No claim that walking is fixed follows from this proposal. Do not initialize arbitrary speeds to compensate.

Original comparison operand order is represented with SSE MAXSS and explicit unordered checks; inverse-square-root refinements require noncontracting arithmetic. Verify actual target architecture, compiler FP contraction/fast-math settings, includes, and build before integration. A generator render is not a compile check.
