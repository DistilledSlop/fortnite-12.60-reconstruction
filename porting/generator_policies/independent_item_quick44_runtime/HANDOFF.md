# Independent item and weapon getters

Twelve source proposals. `manifest-entries.json` records exact reflected exec addresses and bodies. `native-evidence.json` pins the full original image SHA-256 and raw complete wrapper and leaf windows (with bytes and individual hashes). The scalable-float adapter windows identify the native conversion path; the corresponding canonical `FScalableFloat` APIs are already used by item stack recovery. No canonical files, builds, runtime checks, or tests were changed/run.

The eight `AFortWeaponRanged_Ostrich` methods each dispatch directly to a leaf which adds the original field offset to `this` and calls `FScalableFloat` with level 0 and null context. Original field offsets: FireRate 0xf78, AutofireDelay 0xf98, RocketsCooldown 0xfb8, TimeToLoadOneAmmoCharge 0xfd8, AimPointCacheRange 0xff8, MinRocketsForFiring 0x1018, AmmoPerCharge 0x1038 and MaxRockets 0x1058. Integer methods use the same native integer adapter as `item_stack_runtime` (`cvttss2si`); float methods use the native level-zero adapter. Reflection identifies all eight as `FScalableFloat` and the fields are public in the generated class. The reflected wrappers store either EAX or XMM0 according to return type.

Three `UFortDecoItemDefinition` predicates: `ShouldAllowAnyFloorPlacement` reads original offset 0xb34 mask 0x80; `ShouldDisableLocationLerpWhilePlacing` reads 0xb31 mask 0x80. `ShouldDestroySmallObjectsWhenPlaced` returns the 0xb32 mask 0x20 field only when `bForceIgnoreOverlapTest` (0xb31 mask 1) is clear. These masks are independently named in `porting/generated/reflection/bool_bits.json`; both branches and returns are captured.

`UFortGadgetItemDefinition::HasTrackedAttributes` directly compares signed array count at 0x848 to zero (`setg`); reflected `TrackedAttributes` begins at 0x840. The C++ expression preserves the signed comparison.

No matching declaration occurs in their generated headers; these are class-local reflected methods, not inherited methods.
