# Weapon charge range

Proposal only; no canonical source edits or build/tests. `native-evidence.json` pins contiguous original image bytes for the helper, three native callers, reflected wrappers, and min/max/ammo/instigator callees. The helper has discontiguous PE function metadata; its 1076-byte probe window covers through the final cold initialization path. The source requires parent integration of `NativeGetWeaponStats`, `NativeSupportsCharge`, `NativeAmmoCostForCharge`, and the native pawn ability-system interface virtual; no substitute direct component field.

0x142695260 calls the AActor instigator accessor 0x141125940, casts to AFortPawn, calls the IAbilitySystemInterface virtual and captures source snapshot `UFortWeaponAttrSet::WeaponChargeRate`. The checked property is initialized once; capture spec is filled by the ability component. It obtains owned tags from WeaponData (when nonnull), then ability-component owned tags, appends the former to the latter, and uses this union as SourceTags with base 1.0. The result starts at 1.0, remains so on failed evaluation, and is floored to 0.05 inside the nonnull ability-component branch. COMISS/JA floors NaN too. Outputs start at zero; if weapon stats virtual 0x6a8 returns nonnull, min and max are fields +0x124/+0x128 (proven helper 0x14266e310/0x14266e1a0), divided by the multiplier.

0x14269b900 and 0x14269b9a0 call stats before GetWorld regardless of stats result, require both plus supports-charge, then call the range helper (which calls stats again). First requires ChargeTime > min and computes (ChargeTime-min)/(max-min); second requires min > 0 and computes ChargeTime/min. Both clamp with ordered SSE comparisons; NaNs return zero. No extra denominator guard. 0x14269ba70 calls ammo-cost helper with charge=1 for nonnull stats, otherwise uses 1, then divides current AmmoCount by that integer and clamps with the same ordered rules. The callee enforces each ammo cost at least 1. The decompiler omits most of this last function; its assembly establishes all operations.

Potential integration checks: generated inherited `GetInstigator` and `GetOwnedGameplayTags` visibility, and the inferred helper declaration are parent-owned.
