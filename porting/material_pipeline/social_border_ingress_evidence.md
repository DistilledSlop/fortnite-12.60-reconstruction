# Source-derived Social border dynamic texture-size fixture

This fixture combines the original material/atlas/shader source evidence in [social_border_source_evidence.md](social_border_source_evidence.md) with two pinned original executable proofs. The source-only predecessor and its 46-input receipt remain unchanged.

The original direct-vector caller proof `texture-property-caller-proof-2/receipt.json`, SHA-256 `03a19ce546da78b2a0229d909d107c5e8f76af51fc05d78a440c839101535c13`, establishes that `FUniformExpressionSet::FillUniformBuffer` clears all four output lanes to positive zero immediately before invoking each direct vector root. The original size-property getter writes width and height to R/G on success, leaving B/A untouched; a missing texture or resource leaves all four cleared lanes. This is a proof for **direct vector roots**, not nested property expressions.

The original curve-atlas getter proof `original-curve-atlas-reference-proof-1/receipt.json`, SHA-256 `f007855d75984f806382e05b2b79a1cc2899b28edc28ee032fc1372569e2a202`, identifies the original `MaterialExpressionCurveAtlasRowParameter` vtable getter as returning its Atlas member at offset `0x68` and its capability getter as true. The complete source list has Atlas getters at positions 3 and 9, both naming `CA_SocialPanel`; the intervening function closure adds no textures. The original ordered AddUnique traversal therefore yields exactly `/Game/UI/SocialPanel/Art/CA_SocialPanel.CA_SocialPanel` at referenced-texture index 0.

The original direct vector root at index 2 remains a dynamic `{type: TextureSize2D, texture_parameter_index: 0}` operation in the v5 runtime fixture. Slot 0 refers to the separate original plain `Texture` entry, which has no parameter identity, source texture index 0 and sampler source 2. It is **not replaced by a constant**. The independently computed source oracle expects `[32, 32, +0, +0]` from the actual original atlas dimensions, and `[+0, +0, +0, +0]` if its texture/resource is missing. Tests also evaluate a different synthetic dimension pair to ensure the bounded oracle remains dynamic. Nested or scalar-position texture properties, non-size modes, altered source identity, incorrect sampler, or altered proof/order fail closed.

The fixture retains all 19 original shader records and seven Slate associations (six unique programs).
