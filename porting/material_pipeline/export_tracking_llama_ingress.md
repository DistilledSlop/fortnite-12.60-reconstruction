# TrackingLlama offline ingress

`export_tracking_llama_ingress.py --output porting/generated/material_pipeline/tracking-llama-bundle-NEW` writes a v2 bundle and generic manifest for the original parent material. The output path must be new. Defaults refer to the source inventory, shader reports under `porting/generated/material_pipeline/tracking-llama-shaders-1`, and the pinned scratch receipts in `/tmp/tracking-llama-texture-context-1` and `/tmp/tracking-llama-texture-frame-1`; command options can select those inputs explicitly. These scratch artifacts and the original extracted source files are required for reproduction.

`prove_tracking_llama_texture_context.py --function-reports /tmp/tracking-llama-texture-context-1/functions --fresh-inventory /tmp/tracking-llama-texture-context-1/fresh-inventory.json --out /tmp/tracking-llama-texture-context-1/proof-NEW.json` replays the bounded original reference-array evidence. It checks the source, export map, function report source hashes, fresh inspection and complete compiled resource. The single regular texture uniform indexes the one proven reference, Icon-Llama-NoEyes, subject to the original evaluator's expression-local pointer and PostLoad gates documented in `original_texture_context.md`.

The exporter reparses the original complete 19-record resource and preserves all archive wrappers, evaluates numeric defaults and parameter perturbations, revalidates the seven mapped shader programs and reflected descriptor provenance, and checks all nine original DXT5 mips against the pinned texture framing receipt and source bytes. The shaders have no View descriptor. The receipt records inspector defaults separately; effective original sampler and sRGB are not inferred. This is offline source conversion, not runtime loading, GPU rendering, or pixel parity evidence.

Run `python3 porting/material_pipeline/test_export_tracking_llama_ingress.py` for source and rejection checks. The shader reports, source files, and scratch receipts must be available for the tests.
