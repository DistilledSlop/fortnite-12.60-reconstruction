# Paper2D source instance legacy overrides

`Cue4Inspect --legacy-material-start` locates the end of UE tagged properties and the UObject GUID flag using the package name map and object version, checks the tag list against the ordinary object parser, and reports the bounds and source SHA-256. This narrowly scoped probe requires an uncooked, unfiltered version-379 material instance constant with a static permutation; it reads a standalone `.uasset`. It does not read shader maps or execute Unreal Engine.

`decode_paper2d_legacy_overrides.py` reads forward from that offset, verifies the source hash and the full export boundary, and supports only version 379 with no custom versions, three empty static-parameter arrays, and zero inline shader resources. It rejects every other case. The layout follows `FStaticParameterSet::Serialize` in Engine `Public/StaticParameterSet.h`, `SerializeInlineShaderMaps` in `Private/Materials/Material.cpp`, and `UMaterialInstance::Serialize` in `Private/Materials/MaterialInstance.cpp`. Those source files, package, tool, reports, and commands are hashed in the generated receipt. The values are evidence of serialized source behavior, not a test of an Editor cook.

For the inspected source asset, the export is `[30256, 30724)` and the native tail begins at 30674. Three zero counts and a zero shader-resource count precede the old override fields. The blend override flag is true and its byte enum is 2 (`BLEND_Translucent`). The mask-clip, shading-model, and two-sided override flags are false; their stored values therefore do not replace the parent values. In particular, the stored shading enum 1 differs from the original instance's stored unlit enum, but the flag is false in both reports. The current source parent supplies masked/unlit/two-sided, and `UMaterialInstance::UpdateOverridableBaseProperties` uses the parent when each override flag is false. The tail ends exactly at the export boundary. The scalar `RefractionDepthBias` is zero; the old source stores a legacy parameter name, which the engine upgrades to parameter info on load.

The preserved cooked original's override has the same active blend override, and its mask-clip, shading and two-sided override flags are absent (default false). Comparing compiled original shader behavior with the source parent graph requires the separate shader-semantics evidence. Neither this decoding nor that comparison proves original-pixel parity or a successful cook.
