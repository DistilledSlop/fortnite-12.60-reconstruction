How this is measured

Weights and manual percentages are edited in porting/progress/components.json. The generator is porting/progress/progress.py, which reads committed files via git archive at HEAD and ignored local outputs. It records one history point per commit through .githooks/post-commit. Measures only count what is committed; uncommitted stubs and generated artifacts do not add progress unless they are local outputs named in a measure. Denominators come from the tracked porting/progress/totals.json (regenerated by refresh_totals.py from local extraction data), and run checks from the tracked porting/progress/evidence.json (written by record_evidence.py). The dashboard splits the overall into the objective share (git and local), the evidence-based share (adds documented) and the manual-estimate share, so the size of the subjective part is always visible next to the figure it affects.
