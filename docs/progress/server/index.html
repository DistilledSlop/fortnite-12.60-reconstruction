Fortnite 12.60 dedicated-server progress

The server can host a local match for the original 12.60 client, including a Battle Bus drop onto Apollo. The goal is a complete multiplayer match with authoritative gameplay, replication, and the backend services the original client uses.

114/178 server checks implemented (64.0%). 80 are verified, 34 await verification, 64 remain open, and 7 client-only checks are tracked outside the server score.

Coverage = (implemented checks + verified checks) ÷ all server checks. Area and capability scores use the same formula. Every check has equal weight. Verified means the stated behavior has a recorded headless test, service test, or original-client observation. Implementation-only checks have a source reference. Each check contributes at most one point.
